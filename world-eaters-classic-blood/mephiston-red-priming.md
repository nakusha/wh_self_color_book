# Mephiston Red 프라이밍 (차량 · 데몬 엔진)

![Classic Blood Reference Sheet](images/classic-blood-reference-sheet.png)

이 문서는 Chaos Rhino와 Forgefiend처럼 **면적이 큰 모델**을 Citadel `Mephiston Red Spray`로 프라이밍했을 때의 작업 순서를 정리합니다. [기본 도료 문서](basic-paints.md)의 Classic Blood 레시피는 `Chaos Black` 프라이머를 기준으로 쓰여 있으므로, 컬러 프라이머를 쓰면 **순서가 뒤집힙니다.** 그 차이를 먼저 이해하고 시작해야 합니다.

## 왜 차량만 다르게 가는가

| 기준 | Chaos Black | Mephiston Red |
|---|---|---|
| 갑옷 basecoat 작업량 | Khorne Red 2~3회 필요 | 이미 끝난 상태로 시작 |
| 그림자 | 틈에 검정이 남아 자동 생성 | 없음. 직접 만들어야 함 |
| 색의 무게감 | 무겁고 어두움 | 가볍고 밝음 |
| 발색 균일도 | 붓 자국 관리 필요 | 대형 평면에서 압도적으로 유리 |
| 적합 대상 | 보병, Eightbound | Rhino, Forgefiend, Land Raider |

Rhino 한 대의 갑옷 면적은 대략 보병 10기와 맞먹습니다. 그 넓은 판에 `Khorne Red`를 붓으로 얼룩 없이 올리는 작업은 시간도 오래 걸리고 실패 확률도 높습니다. 반대로 차량은 어차피 **panel line wash와 웨더링**으로 음영을 만들기 때문에, 프라이머가 주는 검은 그림자에 덜 의존합니다. 그래서 차량과 데몬 엔진에서는 `Mephiston Red` 프라이밍이 손해보다 이득이 큽니다.

### 사고방식의 전환

| 프라이머 | 작업 방향 |
|---|---|
| Chaos Black | **Bottom-up.** 어두운 상태에서 밝혀 올림 |
| Mephiston Red | **Top-down.** 밝은 상태에서 어둡게 깔고 중앙만 되살림 |

> ⚠ 가장 흔한 실패는 `Mephiston Red` 위에 곧바로 하이라이트부터 넣는 것입니다. 그러면 밝은 빨강 위에 밝은 빨강을 올리는 셈이라 형태가 전혀 읽히지 않습니다. **먼저 어둡게 만드는 단계**를 반드시 넣으세요.

## 스프레이 작업 조건

| 항목 | 기준 |
|---|---|
| 온도 | 18~25℃ |
| 습도 | 50% 이하 |
| 거리 | 20~25cm |
| 패스 | 얇게 2~3회, 한 번에 두껍게 금지 |
| 캔 흔들기 | 최소 2분 |
| 테스트 분사 | 종이나 스푼에 1회 |
| 재도장 간격 | 15~20분 |
| 본작업 시작 | 완전 건조 후 (가능하면 24시간) |

> ⚠ 습도가 높으면 표면이 가루처럼 거칠어집니다(frosting). 이 상태로 진행하면 wash가 얼룩지고 웨더링이 지저분해집니다. 거칠면 아깝더라도 사포로 정리하고 다시 올리세요.

### 분사 각도

| 모델 | 각도 |
|---|---|
| Chaos Rhino | 위, 좌, 우, 앞, 뒤 5방향 |
| Forgefiend | 5방향 + 뒤집어서 배 아래와 다리 안쪽 |

Forgefiend는 다리 사이, 포신 아래, 몸통 하부에 사각이 많습니다. 한 방향에서만 뿌리면 조립 후 **빨강이 안 닿은 회색 플라스틱**이 그대로 보입니다.

### 선택 사항: Zenithal 변형 (강력 추천)

Classic Blood 특유의 무게감을 유지하고 싶다면 두 단계로 나눕니다.

1. `Chaos Black Spray`를 전체에 얇게
2. 완전 건조 후 `Mephiston Red Spray`를 **위 45도에서만**

하단, 트랙 위쪽, 패널 아래, 다리 안쪽에 검정이 남아 그림자가 자동으로 생깁니다. 스프레이 캔 하나와 20분을 더 쓰지만, 이후 셰이드 작업이 절반으로 줄어듭니다.

## 프라이밍 이후 달라지는 red armor 순서

| 단계 | Chaos Black 시작 | Mephiston Red 시작 |
|---|---|---|
| 1 | Primer: Chaos Black | Primer: Mephiston Red Spray |
| 2 | Basecoat: Khorne Red 2회 | **Shadow: Khorne Red 글레이즈** (하단, 패널 아래, 틈) |
| 3 | Layer: Mephiston Red | Panel wash: Berserker Bloodshade (라인에만) |
| 4 | Shade: Berserker Bloodshade | Re-layer: Mephiston Red (패널 중앙 복구) |
| 5 | Re-layer: Mephiston Red | Highlight: Evil Sunz Scarlet |
| 6 | Highlight: Evil Sunz Scarlet | Extreme: Wild Rider Red |
| 7 | Extreme: Wild Rider Red | — |

단계 수는 같지만 **2번의 성격이 반대**입니다. 검정 프라이머에서는 색을 채우는 단계, 빨강 프라이머에서는 색을 눌러 앉히는 단계입니다.

### Khorne Red 글레이즈 만드는 법

| 항목 | 값 |
|---|---|
| 비율 | Khorne Red 1 : 물(또는 Lahmian Medium) 2~3 |
| 올리는 위치 | 패널 하단, 트랙 가드 아래, 다리 안쪽, 해치 그늘 |
| 횟수 | 2~3회 얇게, 아래로 갈수록 한 번씩 더 |
| 금지 | 한 번에 진하게 올려 경계선 만들기 |

💡 Pro Tip  
글레이즈는 "칠한다"기보다 **아래에서 위로 색을 흘려 넣는다**는 느낌으로 합니다. 붓을 패널 하단에 대고 위쪽으로 갈수록 힘을 빼면 경계가 자연스럽게 사라집니다.

## 셰이드, 핀워시, 글레이즈 — 무엇이 다른가

셋 다 "묽은 도료를 올린다"는 점이 같아서 가장 많이 헷갈립니다. 차이는 딱 하나, **도료를 어디로 흘러가게 두느냐**입니다.

| | 셰이드 (Shade) | 핀워시 (Pin Wash) | 글레이즈 (Glaze) |
|---|---|---|---|
| 하는 일 | 홈 **전체**를 한 번에 어둡게 | **선 하나**만 어둡게 | 넓은 면의 **색 자체**를 이동 |
| 쓰는 도료 | Berserker Bloodshade, Nuln Oil | 같은 셰이드를 더 묽게 | 일반 도료 + 물/미디엄 |
| 농도 | 원액 그대로 | 셰이드 1 : 물 1 | 도료 1 : 물 2~3 |
| 올리는 법 | 붓에 머금어 부위에 **떨어뜨림** | 붓끝을 선에 대고 **흘려보냄** | 넓게 여러 번, **경계 없이** |
| 브러시 | 2호 (많이 머금는 것) | 0호 (끝이 뾰족한 것) | 2호 (물을 많이 머금는 것) |
| 마른 뒤 | 홈이 어둡고 면도 살짝 탁해짐 | 선만 어둡고 면은 그대로 | 색이 통째로 한 단계 이동 |
| 차량에 | ❌ 넓은 면은 얼룩 | ✅ 패널 라인 | ✅ 패널 하단 |
| 보병에 | ✅ 한 번에 정리 | ✅ 작은 장식 | ✅ 마무리 보정 |

> **한 줄 요약** — 셰이드는 **덮는** 것, 핀워시는 **긋는** 것, 글레이즈는 **물들이는** 것.

### 왜 차량에는 전체 셰이드가 안 되는가

셰이드는 마르면서 안료가 가장자리로 밀려 **테두리 자국(tide mark)** 을 남깁니다. 보병은 면이 작아 이 자국이 디테일 사이에 묻히지만, Rhino 측면처럼 손바닥만 한 평면에서는 자국이 그대로 드러납니다.

그래서 차량의 어둠은 두 가지로 나눠 만듭니다.

| 만들 어둠 | 도구 |
|---|---|
| **넓은 면의 그늘** (패널 하단, 트랙 가드 아래) | `Khorne Red` 글레이즈 |
| **선과 홈의 어둠** (패널 라인, 리벳 주변) | `Berserker Bloodshade` 핀워시 |
| **가장 깊은 구멍** (볼트, 해치 경계) | `Nuln Oil` 점으로 |

## 셰이드 설계

| 부위 | 방법 | 농도 |
|---|---|---|
| 패널 라인 | `Berserker Bloodshade` 핀워시 — **선에만** | 셰이드 1 : 물 1 |
| 깊은 틈, 볼트 구멍 | `Nuln Oil` 소량, 붓끝으로 점 | 원액 |
| 리벳 주변 | `Agrax Earthshade` 아주 소량 | 원액 |
| 패널 하단 넓은 면 | `Khorne Red` 글레이즈 | 도료 1 : 물 2~3 |
| 넓은 면 전체 | **셰이드 금지** | — |

> ⚠ `Berserker Bloodshade`를 차량 전체에 덮으면 갑옷이 탁한 자주색으로 뜨고, 마르면서 얼룩이 크게 남습니다. 보병에서 통하던 "전체 wash"는 차량에서는 통하지 않습니다.

### 핀워시가 흘러가지 않을 때

무광 표면에서는 도료가 선을 따라 흐르지 않고 그 자리에 멈춰 방울이 됩니다. 순서를 이렇게 바꾸세요.

1. 광택 바니시를 한 겹 올립니다. 표면 장력이 낮아집니다.
2. 핀워시를 넣습니다. 도료가 라인을 따라 스스로 달려갑니다.
3. 완전 건조 후 무광 바니시로 되돌립니다.

### 글레이즈 실전 요령

- 붓에 도료를 묻힌 뒤 **팔레트 가장자리에서 한 번 훑어** 물기를 뺍니다. 물방울이 맺히면 그 자리에 얼룩이 생깁니다.
- **아래에서 위로**, 위로 갈수록 힘을 빼면 경계가 저절로 사라집니다.
- 한 번에 진하게 올리지 말고 **2~3회 얇게**. 아래로 갈수록 한 번씩 더 올립니다.
- 각 회차 사이에 완전히 말립니다. 젖은 층 위에 겹치면 아래층이 들립니다.

### 과하게 넣었을 때

| 증상 | 원인 | 복구 |
|---|---|---|
| 면 전체가 탁한 자주색 | 넓은 면에 셰이드를 덮음 | `Mephiston Red` 재레이어 후 핀워시로 다시 |
| 홈 밖에 테두리 자국 | 셰이드 과다 + 무광 표면 | 해당 면 재레이어 → 광택 → 핀워시 |
| 글레이즈 경계선이 보임 | 한 번에 진하게 | 더 묽게 여러 번 덧칠해 경계를 흐림 |
| 색이 분홍빛으로 뜸 | 물이 많아 안료가 분리됨 | 물 대신 Lahmian Medium 사용 |
| 홈이 여전히 얕아 보임 | 핀워시가 마르며 옅어짐 | 같은 자리에 한 번 더. 한 번에 진하게는 금지 |

## 금속색을 올릴 때 주의

`Mephiston Red` 위에 `Leadbelcher`를 바로 칠하면 아래 빨강이 비쳐 **구릿빛으로 얼룩집니다.** 트랙, 포신, 체인처럼 금속이 넓은 부위는 반드시 한 단계를 끼워 넣으세요.

| 순서 | 도료 |
|---|---|
| 1 | Abaddon Black 1회 (또는 Chaos Black 부분 스프레이) |
| 2 | Leadbelcher |
| 3 | Nuln Oil |
| 4 | Leadbelcher 또는 Ironbreaker 상단 |

## 샘플 테스트

본작업 전에 여분 부품이나 플라스틱 스푼에 아래를 먼저 확인합니다.

| 확인 항목 | 합격 기준 |
|---|---|
| 표면 질감 | 손으로 만졌을 때 매끄러움, 가루 느낌 없음 |
| 몰드 | 리벳과 패널 라인이 살아 있음 |
| 색 균일도 | 회색 플라스틱이 비치지 않음 |
| 글레이즈 반응 | Khorne Red가 경계 없이 퍼짐 |
| Wash 반응 | Bloodshade가 라인을 따라 흐름 |

## Checklist

- [ ] 습도와 온도를 확인하고 스프레이했다.
- [ ] 얇게 2~3회 나눠 뿌려 몰드를 살렸다.
- [ ] 다리 안쪽과 하부까지 빨강이 닿았다.
- [ ] Zenithal 변형을 쓸지 결정했다.
- [ ] 하이라이트 전에 **어둡게 만드는 단계**를 계획했다.
- [ ] 셰이드는 전체 wash가 아니라 pin wash로 하기로 했다.
- [ ] 금속 부위는 검정 basecoat를 한 번 끼우기로 했다.
