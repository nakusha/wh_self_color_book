# World Eaters Classic Blood 기본 사용 도료

![Classic Blood Reference Sheet](images/classic-blood-reference-sheet.png)

이 문서는 World Eaters를 **Classic Blood** 조합으로 칠하기 위한 기본 도료 목록입니다. 목표는 조색을 최소화하면서도 `shade`, `layer`, `highlight`, `extreme highlight`를 모두 사용하는 것입니다. 기본 마린과 Eightbound 계열 모델을 같은 군대처럼 보이게 하되, Eightbound는 피부와 뼈 장식의 비중이 크므로 갑옷을 너무 밝게 만들지 않는 것이 핵심입니다.

## Scheme Goal

| 요소 | 방향 |
|---|---|
| 갑옷 | 어두운 피색 red armor |
| 장식 | 낡은 aged brass trim |
| 무기 | 검게 눌린 blackened steel |
| 뼈 | 따뜻한 warm bone |
| 피부 | 창백하고 멍든 pale bruised flesh |
| 베이스 | dark ash rubble |
| 마감 | 갑옷은 무광, 금속은 약한 satin |

> ⚠ Classic Blood는 밝은 빨강을 많이 쓰는 스킴이 아닙니다. 밝은 색은 모서리와 높은 패널에만 남겨야 피부, 뼈, brass 장식이 같이 살아납니다.

## Citadel Primer 선택

사용 중인 프라이머가 Citadel spray라면 아래 기준으로 고르면 됩니다.

| Citadel Spray | 추천도 | 사용 이유 | 주의점 |
|---|---:|---|---|
| Chaos Black | ★★★★★ | 깊은 red, black metal, 어두운 틈을 만들기 가장 좋음 | 첫 red basecoat가 2회 필요할 수 있음 |
| Mephiston Red | ★★★★☆ | 전군 도색 속도가 빠름 | 그림자가 약해져서 shade를 더 신중히 넣어야 함 |
| Mechanicus Standard Grey | ★★★☆☆ | 빨강 발색과 음영의 중간점 | 분위기가 조금 밝아질 수 있음 |
| Grey Seer | ★★☆☆☆ | 밝은 Arena Gore 계열에는 좋음 | Classic Blood에는 너무 산뜻함 |
| Wraithbone | ★★☆☆☆ | bone, flesh 발색은 좋음 | red armor가 가벼워 보이기 쉬움 |
| White Scar | ★☆☆☆☆ | 선명한 빨강에는 유리 | World Eaters의 무게감이 줄어듦 |
| Leadbelcher | ★★☆☆☆ | 금속이 많은 차량/특수 모델에 가능 | red armor 작업이 번거로움 |
| Retributor Armour | ★★☆☆☆ | brass trim 초벌이 빠름 | red armor 위에 금색 입자가 거칠게 남을 수 있음 |
| Zandri Dust | ★★☆☆☆ | bone-heavy 변형에 좋음 | Classic Blood 기본 마린에는 비추천 |

### 추천 프라이머

| 목적 | 선택 |
|---|---|
| 최고 안정성 | Chaos Black |
| 빠른 전군 도색 | Mephiston Red |
| 밝은 빨강 변형 | Mechanicus Standard Grey |
| Eightbound 피부 작업 우선 | Chaos Black 후 피부만 밝게 basecoat |

💡 Pro Tip  
Classic Blood에서 `Chaos Black`은 단순한 밑색이 아니라 그림자 설계입니다. 갑옷 틈, 백팩 아래, 무기 안쪽, 체인 사이에 검은색이 조금 남으면 모델이 훨씬 강하게 보입니다.

## Full Paint Recipe

### Red Armor

| 단계 | Paint | 설명 |
|---|---|---|
| Primer | Chaos Black Spray | 틈과 그림자를 검게 유지 |
| Basecoat | Khorne Red | 얇게 2회, 검은 틈은 남김 |
| Layer | Mephiston Red | 패널 중앙과 위쪽 면만 |
| Shade | Berserker Bloodshade | 패널 경계, 리벳 주변, 하단에 집중 |
| Re-layer | Mephiston Red | shade 후 탁해진 중앙을 복구 |
| Highlight | Evil Sunz Scarlet | 갑옷 모서리와 무릎/손등 위쪽 |
| Extreme Highlight | Wild Rider Red | 가장 날카로운 점만 |

> ⚠ `Wild Rider Red`는 많이 쓰면 갑옷이 orange armor처럼 보입니다. 무릎, 손가락, 투구, 어깨 끝의 짧은 선에만 사용하세요.

### Aged Brass Trim

| 단계 | Paint | 설명 |
|---|---|---|
| Basecoat | Balthasar Gold | trim 전체 |
| Shade | Agrax Earthshade | 리벳 주변, 장식 안쪽 |
| Deep Shade | Nuln Oil | 아주 깊은 틈만 |
| Layer | Balthasar Gold | 넓은 장식 복구 |
| Highlight | Sycorax Bronze | 상단 edge |

💡 Pro Tip  
Brass는 너무 밝게 칠하면 red armor보다 먼저 보입니다. World Eaters에서는 brass가 갑옷을 장식해야지, 갑옷을 이기면 안 됩니다.

## Marker Tips

Classic Blood에서는 marker를 보조 도구로만 쓰는 것이 좋습니다.

| 부위 | Marker 추천 | 이유 |
|---|---|---|
| 큰 red armor 패널 | 비추천 | 마커 자국이 남기 쉬움 |
| brass trim 초벌 | 가능 | 얇은 테두리 작업 속도 상승 |
| rivet | 추천 | 일정하게 점 찍기 좋음 |
| chain | 가능 | 어두운 금속 초벌에 유용 |
| skull | 비추천 | 뼈색은 붓 레이어가 더 자연스러움 |
| Eightbound flesh | 비추천 | 피부 그라데이션이 뭉개짐 |

추천 tip size:

| 작업 | Tip |
|---|---|
| rivet, 작은 symbol | 0.7mm |
| trim 초벌 | 1.0mm |
| 큰 금속 무기 초벌 | 1.5mm |

## Checklist

- [ ] Citadel `Chaos Black Spray` 또는 `Mephiston Red Spray`를 선택했다.
- [ ] red armor는 `Khorne Red → Mephiston Red → Berserker Bloodshade → Evil Sunz Scarlet` 순서로 준비했다.
- [ ] brass trim용 `Balthasar Gold`와 `Agrax Earthshade`를 준비했다.
- [ ] 무기용 `Leadbelcher`와 `Nuln Oil`을 준비했다.
- [ ] Eightbound 피부용 `Rakarth Flesh`, `Druchii Violet`, `Flayed One Flesh`를 준비했다.
- [ ] 뼈 장식용 `Zandri Dust`, `Ushabti Bone`, `Screaming Skull`을 준비했다.
- [ ] 최종 마감은 갑옷 무광, 금속 satin으로 분리하기로 했다.
