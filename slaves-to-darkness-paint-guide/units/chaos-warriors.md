# Chaos Warriors

![Chaos Warriors](../images/unit-chaos-warriors-01.jpg)

## Introduction

Chaos Warriors는 Spearhead의 기준 유닛입니다. 검은 갑옷, 청동 trim, steel weapon, dark shield가 모두 반복되므로 이 유닛을 안정적으로 칠하면 박스 전체의 완성도가 올라갑니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 기준 모델 확립 | 전군 색 기준 |
| batch painting | 공정별 반복으로 속도 확보 |
| 방패 전면 품질 | 분대의 첫인상 |
| 마커 적극 활용 | trim, rivets, shield symbols |

## Difficulty

Intermediate. 모델 수가 많고 trim 반복이 많아 집중력이 중요합니다.

## Estimated time

## Preparation

1. 한 명을 기준 모델로 칠합니다.
2. 나머지는 armor, trim, weapon, shield 순서로 batch painting합니다.
3. 방패는 가능하면 별도로 잡고 칠합니다.
4. 마커는 모든 모델에 바로 쓰지 말고 기준 모델에서 먼저 테스트합니다.

## Step-by-step workflow

1. 전체 모델에 [Armor Recipe](../recipes/armor.md)를 적용합니다.
2. [Bronze Recipe](../recipes/bronze.md)로 trim을 batch 처리합니다.
3. Rivets와 chains는 steel marker 또는 [Steel Recipe](../recipes/steel.md)로 빠르게 처리합니다.
4. [Shield Recipe](../recipes/shield.md)로 방패 전면을 정리합니다.
5. [Leather Recipe](../recipes/leather.md)로 손잡이와 벨트를 칠합니다.
6. [Base Recipe](../recipes/base.md)로 모든 베이스를 한 번에 완성합니다.
7. 최종적으로 분대 전체를 세워 edge highlight 밝기를 비교합니다.

## Marker Tips

Chaos Warriors는 마커 효율이 가장 좋은 유닛입니다.

| 부위 | 마커 추천 | 이유 |
|---|---|---|
| Bronze trim | 권장 | 반복 장식 속도 |
| Shield symbols | 권장 | 양각 문양 초벌 |
| Rivets | 강력 추천 | 점 작업 반복 |
| Chains | 권장 | 빠른 steel 초벌 |
| Large shield face | 비추천 | 검은 면이 지저분해짐 |
| Cloth/fur | 비추천 | 질감과 주름 필요 |

## Professional tips

💡 Pro Tip

분대 전체의 방패 상단 edge를 같은 밝기로 맞추면, 개별 모델의 작은 차이는 거의 보이지 않습니다.

💡 Pro Tip

Warriors는 Lord보다 한 단계 낮은 하이라이트로 유지하세요. 그래야 [Chaos Lord](chaos-lord.md)가 자연스럽게 중심으로 보입니다.

## Common mistakes

- 모델 한 명씩 완성해 분대 색이 흔들리는 것
- 방패 중앙을 마커로 칠해 자국이 남는 것
- trim을 너무 밝게 칠해 갑옷보다 튀는 것
- 베이스를 모델마다 다르게 처리하는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 분대 색이 다름 | batch가 아닌 개별 도색 | 같은 단계별로 다시 정리 |
| shield가 지저분함 | symbol 번짐 | Black으로 경계 재정리 |
| 너무 어둡다 | edge 부족 | 방패/헬멧 상단만 추가 |
| 마커 색이 튄다 | wash 부족 | Sepia/Black Wash로 낮춤 |

## Summary

Chaos Warriors는 박스의 기준입니다. 이 유닛을 먼저 완성한 뒤 [Chaos Knights](chaos-knights.md)와 [Chaos Lord](chaos-lord.md)에 같은 팔레트를 확장하세요.

## Checklist

- [ ] 기준 Warrior 한 명을 완성했다.
- [ ] 분대는 공정별 batch painting으로 진행했다.
