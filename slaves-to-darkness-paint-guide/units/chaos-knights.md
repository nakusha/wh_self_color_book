# Chaos Knights

![Chaos Knights](../images/unit-chaos-knights-01.jpg)

## Introduction

Chaos Knights는 Spearhead의 속도와 무게를 보여주는 유닛입니다. 기수의 갑옷, 말의 barding, lance, shield, leather straps가 모두 크게 보이므로 Warriors보다 면적 관리가 중요합니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 무거운 말 갑옷 | 큰 검은 면을 단조롭지 않게 |
| 돌격 방향 | lance 끝을 가장 밝게 |
| 장비 분리 | leather straps와 bronze trim 구분 |
| 마커 제한 활용 | rivets, chains, trim 초벌 |

## Difficulty

Advanced. 큰 면과 작은 장식이 함께 있어 순서 관리가 중요합니다.

## Preparation

1. 말과 기수를 분리해 칠할지 결정합니다.
2. lance와 shield는 접근성을 확인합니다.
3. barding의 큰 면은 마커를 쓰지 않습니다.
4. leather straps가 갑옷 trim과 겹치는 순서를 계획합니다.

## Step-by-step workflow

1. 말 barding과 기수 armor에 [Armor Recipe](../recipes/armor.md)를 적용합니다.
2. 큰 면에는 Charcoal을 상단 45도 방향으로 더 넓게 올립니다.
3. trim은 [Bronze Recipe](../recipes/bronze.md)로 처리하되 마커 초벌을 활용합니다.
4. lance와 weapon은 [Weapon Recipe](../recipes/weapon.md)를 사용하고 끝을 밝게 만듭니다.
5. straps와 saddle은 [Leather Recipe](../recipes/leather.md)로 낮은 채도 유지합니다.
6. 베이스는 [Base Recipe](../recipes/base.md)를 사용하고 발굽 주변 먼지를 추가합니다.

## Marker Tips

Knights는 마커가 유용하지만 큰 면에서는 위험합니다.

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| Barding trim | 권장 | 긴 양각 장식 초벌 |
| Rivets | 강력 추천 | 반복 점 작업 |
| Chains | 권장 | 빠른 steel 처리 |
| Lance scratches | 제한적 | 작은 전투 손상 |
| Horse barding plate | 비추천 | 넓은 매끈한 면 |
| Leather final highlight | 비추천 | 붓 선이 더 자연스러움 |

> ⚠ Knights는 면이 크기 때문에 마커 자국도 커 보입니다. 마커는 trim과 rivets에만 두고, barding plate는 붓이나 에어브러시로 처리하세요.

## Professional tips

💡 Pro Tip

말 갑옷은 기수 갑옷보다 살짝 어둡게 두세요. 그러면 rider와 lance가 주인공으로 보입니다.

💡 Pro Tip

lance 끝, shield symbol, rider helmet을 삼각형 시선점으로 잡으면 돌격 포즈가 훨씬 강해집니다.

## Common mistakes

- 말과 기수를 같은 밝기로 칠해 시선이 분산되는 것
- barding plate를 마커로 칠해 줄무늬가 남는 것
- lance 끝이 어두워 돌격 방향이 약해지는 것
- 발굽 주변 먼지를 과하게 넣어 하단이 지저분해지는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| Knight가 단조롭다 | 큰 면 명암 부족 | Charcoal layer와 Neutral Grey edge 추가 |
| rider가 묻힘 | 말 갑옷이 너무 밝음 | 말 쪽 Black glaze |
| lance가 약함 | 끝 하이라이트 부족 | Silver edge와 작은 scratch |
| trim이 번짐 | 마커 과다 | 건조 후 Black 경계 정리 |

## Summary

Chaos Knights는 큰 면과 돌격 방향의 유닛입니다. 마커는 trim과 rivets에 사용하고, 큰 barding은 붓 또는 에어브러시로 매끈하게 유지하세요.

## Checklist

- [ ] 말과 기수의 밝기 우선순위를 정했다.
- [ ] barding 큰 면에는 마커를 쓰지 않았다.
- [ ] lance 끝이 밝고 선명하다.
- [ ] trim과 rivets는 빠르게 초벌 후 붓으로 정리했다.
- [ ] 발굽 주변 먼지가 절제되어 있다.
