# 04 Paints

![Paint Range](images/paints-01.jpg)

## Introduction

이 책의 기본 도료 체계는 `Vallejo Game Color`입니다. **Pale Steel** 스킴은 금속색의 비중이 매우 크기 때문에, 도료를 고를 때 중요한 것은 색 이름이 아니라 **입자 크기와 커버력**입니다. `Gunmetal`, `Chainmail Silver`, `Silver`처럼 밝기 단계가 뚜렷한 금속 3종과, 그 위에 올릴 `Black Wash`, `Sepia Wash`가 이 프로젝트의 뼈대입니다.

마커 페인팅은 공식 보조 방식으로 포함하지만, 현재 공식 제품군 기준으로는 Vallejo의 미니어처용 paint marker 라인을 확인할 수 없습니다. 따라서 마커는 `AK Interactive Real Colors Markers`와 `AK Playmarkers`를 중심으로 추천하고, 색감은 Vallejo Game Color 팔레트에 맞춰 조정합니다.

## Painting goals

| 목표 | 도료 선택 기준 |
|---|---|
| 밝은 강철 갑옷 | 어두운 금속, 중간 금속, 밝은 금속의 3단계 |
| 깊은 홈 | 금속 위에서 얼룩지지 않는 wash |
| 짙은 적색 천 | 채도가 낮고 커버력이 좋은 적색 |
| 따뜻한 뼈 | 노란 기운의 크림색 3단계 |
| 어두운 액자 | 검은 털, 갈색 가죽, 갈색 흙 |
| 마커 보조 | 작은 금속 장식과 반복 점 작업 |

## Difficulty

Beginner. 도료 수를 늘리기보다 **각 금속색의 역할을 분명히 정하는 것**이 훨씬 중요합니다.

## 금속 3단계

Pale Steel에서 가장 자주 쓰는 세 색입니다. 이 세 색의 관계만 이해하면 갑옷, 사슬, 무기, 리벳이 전부 해결됩니다.

| 색 | 밝기 | 쓰는 곳 | 면적 |
|---|---|---|---:|
| Gunmetal | 어두움 | 전체 바탕, 무기, 홈 근처 | 100% |
| Chainmail Silver | 중간 | 판 중앙, 상단 면, 사슬 돌출부 | 40~60% |
| Silver | 밝음 | 모서리, 리벳 상단, 날 끝 | 5~10% |

> ⚠ `Silver`를 면으로 칠하면 갑옷이 **알루미늄 호일처럼** 보입니다. `Silver`는 항상 선과 점으로만 쓰세요.

## Preparation

1. 금속 도료는 다른 색보다 **두 배 더 오래** 흔듭니다. 입자가 바닥에 가라앉아 있습니다.
2. 금속 도료에는 별도 물컵과 브러시를 씁니다. 입자가 다른 색에 섞이면 천과 뼈가 번들거립니다.
3. Metal primer 위와 Black primer 위에 각각 테스트해 발색 차이를 확인합니다.
4. Wash는 금속 위에서 얼룩지기 쉬우므로 카드에서 먼저 흐름을 봅니다.
5. 바니시 후 금속 광택이 얼마나 죽는지 확인합니다.

## Step-by-step workflow

1. `Gunmetal`, `Chainmail Silver`, `Silver`로 갑옷 3단계 카드를 만듭니다.
2. 같은 카드 위에 `Game Wash Black`과 `Sepia Wash`를 각각 올려 비교합니다.
3. `Tinny Tin`, `Brassy Brass`로 청동 trim 카드를 만들고, 은색 옆에 두어 색온도를 확인합니다.
4. `Charred Brown`, `Gory Red`, `Gory Red + Bonewhite`로 천 3단계 카드를 만듭니다.
5. 마커 `Aluminium`, `Dark Aluminium`, `Chipping Color`, `Off White`를 카드에 시험합니다.
6. 실제 모델에는 마커를 작은 장식 초벌에만 쓰고, shade와 highlight는 붓으로 완성합니다.

## Marker Tips

| 마커 색 | 추천 작업 | Vallejo 색과 맞추는 법 |
|---|---|---|
| AK Aluminium | steel rivet, chain 초벌 | Vallejo Gunmetal로 낮추고 Silver로 점 하이라이트 |
| AK Dark Aluminium | 무기 손상, 홈 근처 | Vallejo Gunmetal과 같은 밝기로 사용 |
| AK Chipping Color | 발끝 칩, 방패 손상 | Vallejo Charred Brown과 함께 사용 |
| AK Off White | 뿔 끝, 배너 문양 밑칠 | Vallejo Bonewhite로 따뜻하게 정리 |
| AK Rubber Black | 관절, 가죽 끈 | Vallejo Black/Charcoal 주변에 사용 |
| AK Wood Base | 창대와 손잡이 초벌 | Vallejo Charred Brown wash로 낮춤 |

마커는 rivets, chains, bronze trim, shield symbols, horns의 초벌에 빠릅니다. 하지만 skin, faces, large cloth, fur, **넓은 갑옷 판**에는 권장하지 않습니다.

> ⚠ Pale Steel에서는 갑옷이 밝기 때문에 마커의 스트로크와 광택 차이가 이전 스킴보다 훨씬 잘 드러납니다. 마커는 리벳과 사슬에서 멈추세요.

## Professional tips

💡 Pro Tip

금속 도료는 물로 많이 희석하면 입자가 뭉쳐 얼룩집니다. 물 대신 **metallic medium** 또는 소량의 thinner로 흐름만 조정하세요.

💡 Pro Tip

금속 위 wash는 마르면서 가장자리에 테두리(tide mark)를 남기기 쉽습니다. 한 번에 진하게 넣지 말고 **묽게 두 번**, 홈을 따라 흘려 넣으세요.

💡 Pro Tip

`Silver`가 없다면 `Chainmail Silver`에 `Off White`를 아주 조금 섞어 대신할 수 있습니다. 다만 무광이 되므로 마지막 극점에만 쓰세요.

## Common mistakes

- 금속 도료를 충분히 흔들지 않아 색이 묽고 투명하게 나오는 것
- 금속 도료를 일반 물컵에 씻어 천과 뼈에 금속 입자가 섞이는 것
- `Silver`를 넓은 면에 칠해 갑옷이 호일처럼 보이는 것
- Wash를 한 번에 진하게 넣어 갑옷 전체가 회색으로 탁해지는 것
- 마커 색을 최종색으로 믿고 붓 정리를 생략하는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 금속이 투명하다 | 교반 부족, 과희석 | 충분히 흔들고 2회 얇게 |
| 금속이 거칠다 | 도료량 과다 | 적은 양으로 2회 |
| Wash가 얼룩졌다 | 한 번에 진하게 | `Chainmail Silver` 재레이어 후 묽게 재작업 |
| 천에 반짝임이 있다 | 금속 입자 혼입 | 붓과 물컵 분리, 해당 면 재도색 |
| 바니시 후 금속이 죽었다 | 무광 과다 | Satin Varnish를 금속에만 선택 적용 |

## Summary

Pale Steel의 팔레트는 **금속 3단계 + wash 2종**이 전부입니다. 나머지 색은 그 금속을 받쳐주는 어두운 액자입니다. 실제 부위별 세부 레시피는 [Armor Recipe](recipes/armor.md)부터 이어집니다.

- [ ] 금속 3단계 카드를 만들어 면적 비율을 정했다.
