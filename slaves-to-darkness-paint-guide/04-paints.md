# 04 Paints

![Paint Range](images/paints-01.jpg)

## Introduction

이 책의 기본 도료 체계는 `Vallejo Game Color`입니다. Slaves to Darkness는 어두운 색이 많기 때문에 커버력, 무광 마감, 하이라이트 단계가 중요합니다. Vallejo Game Color는 fantasy와 wargame figure에 맞춘 색 구성이 좋고, `Black`, `Charcoal`, `Neutral Grey`, `Tinny Tin`, `Dark Gunmetal`, `Bonewhite`처럼 이 프로젝트에 필요한 핵심 색을 안정적으로 제공합니다.

마커 페인팅은 공식 보조 방식으로 포함하지만, 현재 공식 제품군 기준으로는 Vallejo의 미니어처용 paint marker 라인을 확인할 수 없습니다. 따라서 마커는 `AK Interactive Real Colors Markers`와 `AK Playmarkers`를 중심으로 추천하고, 색감은 Vallejo Game Color 팔레트에 맞춰 조정합니다.

## Painting goals

| 목표 | 도료 선택 기준 |

| 검은 갑옷 | 검정, 거의 검정, 차가운 회색의 3단계 |
| 낡은 청동 | 붉은 갈색 금속에서 밝은 청동으로 상승 |
| 차가운 강철 | 청동보다 낮은 온도와 높은 반사 |
| 자연 재질 | 낮은 채도의 갈색, 뼈색, 회색 |
| 마커 보조 | 작은 금속 장식과 반복 점 작업 |

## Preparation

1. 모든 도료를 충분히 흔듭니다.
2. 금속 도료에는 별도 물컵과 브러시를 사용합니다.
3. Black primer 위에 각 색을 테스트해 실제 발색을 확인합니다.
4. 마커는 같은 프라이머 위에서 Vallejo 색과 비교합니다.
5. 바니시 후 색이 어두워지는지 확인합니다.

## Step-by-step workflow

1. `Black`, `Charcoal`, `Neutral Grey`로 갑옷 카드 3단계를 만듭니다.
2. `Tinny Tin`, `Brassy Brass`, `Bright Bronze`로 청동 trim 카드를 만듭니다.
3. `Dark Gunmetal`, `Chainmail`, `Silver`로 steel 카드와 chain 테스트를 만듭니다.
4. 마커 `Rubber Black`, `Aluminium`, `Chipping Color`, `Off White`를 카드에 시험합니다.
5. 실제 모델에는 마커를 작은 장식 초벌에만 사용하고, 붓으로 shade와 highlight를 완성합니다.

## Marker Tips

| 마커 색 | 추천 작업 | Vallejo 색과 맞추는 법 |
|---|---|---|
| AK Rubber Black | 관절, 검은 방패 림 | Vallejo Black/Charcoal 주변에 사용 |
| AK Aluminium | steel rivet, chain 초벌 | Vallejo Dark Gunmetal로 낮추고 Silver로 점 하이라이트 |
| AK Dark Aluminium | 무기 손상 | Vallejo Chainmail보다 어둡게 사용 |
| AK Chipping Color | 발끝 칩, 방패 손상 | Vallejo Charred Brown과 함께 사용 |
| AK Off White | 뿔 끝, 문양 밑칠 | Vallejo Bonewhite로 따뜻하게 정리 |
| AK Wood Base | 창대와 손잡이 초벌 | Vallejo Charred Brown wash로 낮춤 |

마커는 armor trim, bronze trim, steel, chains, rivets, shields, symbols, horns의 초벌에 빠릅니다. 하지만 skin, faces, large cloth, fur, large smooth surfaces에는 권장하지 않습니다. 이 부위들은 자연스러운 색 변화나 붓 결 방향이 중요하기 때문입니다.

> ⚠ 마커가 Vallejo Game Color와 정확히 같은 색일 필요는 없습니다. 마커는 초벌이고, 최종 색 조정은 Vallejo 붓 레이어와 wash로 맞춥니다.

## Professional tips

💡 Pro Tip

검은 갑옷은 Black primer 위에 Black을 다시 칠하는 것이 낭비처럼 보이지만, 이후 수정이 쉬운 동일한 표면을 만들어 줍니다.

💡 Pro Tip

금속 도료는 너무 많이 희석하면 금속 입자가 고르게 앉지 않습니다. 물보다 metallic medium이나 소량의 thinner로 흐름만 조정하세요.

## Common mistakes

- 검은 갑옷을 단색 Black으로 끝내는 것
- 금속 도료를 일반 물컵에 씻어 다른 색에 입자가 섞이는 것
- 마커 색을 최종색으로 믿고 붓 정리를 생략하는 것
- 바니시 후 금속 광택이 죽는 것을 테스트하지 않는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 도료가 두껍다 | 물/미디엄 부족 | 팔레트에서 2회 얇게 칠하기 |
| 금속이 거칠다 | 과한 도료량 | 적은 양으로 2회 칠하기 |
| 마커와 붓 색이 다르다 | 브랜드 색상 차이 | wash와 glaze로 통일 |
| 바니시 후 금속이 죽었다 | 무광 과다 | Satin Varnish를 금속에 선택 적용 |

## Summary

도료는 색 이름보다 역할이 중요합니다. Vallejo Game Color를 기준 팔레트로 삼고, 마커는 빠른 초벌 도구로 사용하세요. 실제 부위별 세부 레시피는 [Armor Recipe](recipes/armor.md)부터 이어집니다.
