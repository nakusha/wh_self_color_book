# Armor

![Chaos Warrior Armor](../images/armor-chaos-warrior-01.jpg)

## Introduction

Slaves to Darkness의 갑옷은 검은색이지만, 단순한 검정이 아닙니다. 전투로 닳은 검은 철, 차가운 모서리, 낡은 trim과 연결되는 어두운 표면이어야 합니다. 이 장은 Chaos Warriors, Chaos Knights, Chaos Lord에 모두 적용되는 기본 갑옷 레시피입니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 검게 보이기 | 전체 인상은 Black armor |
| 형태 읽히기 | Charcoal과 Neutral Grey로 모서리만 밝힘 |
| 금속 trim과 분리 | 갑옷은 무광, trim은 금속 광택 |
| 빠른 반복 | Warriors에는 batch painting 가능 |
| 고급 확장 | Lord에는 글레이즈와 극점 추가 |

## Difficulty

Intermediate. 검은 갑옷은 색이 적어 쉬워 보이지만, 하이라이트 면적을 통제하지 못하면 회색 갑옷이 됩니다.

## Preparation

1. 갑옷 판의 몰드라인을 제거합니다.
2. Black primer가 모든 홈에 들어갔는지 확인합니다.
3. trim을 칠하기 전에 갑옷 큰 면을 먼저 정리합니다.
4. 마커는 갑옷 넓은 면에 쓰지 않습니다.

## Step-by-step workflow

1. Black을 갑옷 전체에 얇게 칠해 프라이머 표면과 통일합니다.
2. Charcoal을 상단 면과 넓은 판 중앙에 얇게 올립니다.
3. Black Wash를 패널 사이와 trim 경계에 넣습니다.
4. Neutral Grey로 어깨, 헬멧, 무릎, 방패 상단 모서리를 긋습니다.
5. Neutral Grey + Bonewhite를 아주 조금 섞어 얼굴 주변과 가장 높은 모서리에만 찍습니다.
6. 너무 밝아진 부분은 Black glaze로 낮춥니다.

## Marker Tips

갑옷 큰 면에는 마커를 권장하지 않습니다. 넓고 매끈한 surface에서는 마커 스트로크가 남고, 검은 갑옷 특유의 부드러운 명도 조절이 어렵습니다.

마커를 사용할 수 있는 갑옷 관련 부위는 다음입니다.

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| Armor trim 초벌 | 권장 | 양각 장식만 빠르게 칠함 |
| Rivets | 강력 추천 | 반복 점 작업 |
| Battle chips | 제한적 | 작은 손상점 |
| Large plates | 비추천 | 펜 자국과 광택 차이 |

> ⚠ 갑옷 전체를 Black marker로 칠하면 빠를 것 같지만, 표면 광택과 스트로크가 불균일해져 후반 작업이 더 어려워집니다.

## Professional tips

💡 Pro Tip

검은 갑옷의 하이라이트는 "많이"가 아니라 "정확히"입니다. 어깨와 헬멧 주변만 선명해도 전체 모델이 충분히 읽힙니다.

💡 Pro Tip

Chaos Lord는 같은 레시피에서 edge highlight를 한 단계 더 밝게, Chaos Warriors는 한 단계 낮게 두면 계급 차이가 자연스럽게 생깁니다.

## Common mistakes

- Neutral Grey를 너무 넓게 써 갑옷이 회색이 되는 것
- Black Wash를 전체에 덮어 Charcoal 레이어를 모두 죽이는 것
- trim 전에 갑옷 경계를 정리하지 않는 것
- 마커로 넓은 갑옷을 칠하는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 갑옷이 안 보임 | 하이라이트 부족 | Neutral Grey를 상단 엣지에 추가 |
| 갑옷이 회색임 | 하이라이트 과다 | Black glaze로 넓은 면 낮춤 |
| 엣지가 두꺼움 | 도료량 과다 | Black으로 선 폭 줄이기 |
| 표면이 번들거림 | 마커/바니시 광택 | Matt Varnish 테스트 후 적용 |

## Summary

검은 갑옷은 이 Spearhead의 중심입니다. 갑옷을 어둡게 유지하고 모서리만 정확히 밝히면 [Bronze Recipe](bronze.md)와 [Steel Recipe](steel.md)가 훨씬 선명하게 분리됩니다.

## Checklist

- [ ] Black basecoat로 표면을 통일했다.
- [ ] Charcoal은 상단 면에만 올렸다.
- [ ] Neutral Grey edge가 너무 넓지 않다.
- [ ] 갑옷 큰 면에는 마커를 쓰지 않았다.
- [ ] Matt Varnish로 무광 마감을 계획했다.
