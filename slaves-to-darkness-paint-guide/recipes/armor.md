# Armor

![Chaos Warrior Armor](../images/armor-chaos-warrior-01.jpg)

## Introduction

**Pale Steel** 갑옷은 밝게 닦인 강철 판금입니다. 단순한 은색이 아니라, **판 중앙은 밝고 판 경계와 홈은 거의 검은** 금속이어야 합니다. 밝은 갑옷의 완성도는 하이라이트가 아니라 **어둠의 깊이**로 결정됩니다.

[Primer](../06-primer.md)에서 금속 프라이머를 썼다면 basecoat는 이미 끝난 상태입니다. 이 레시피의 실제 내용은 색을 채우는 것이 아니라 **어둠을 만들고 밝은 면을 되살리는 것**입니다.

이 장은 Chaos Warriors, Chaos Knights, Chaos Lord에 모두 적용되는 기본 갑옷 레시피입니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 밝게 보이기 | 전체 인상은 닦인 강철 |
| 형태 읽히기 | 판 경계와 홈이 어두운 선으로 남을 것 |
| 무기와 분리 | 갑옷은 밝게, 무기는 한 단계 어둡게 |
| 사용감 | 새 갑옷이 아니라 오래 쓴 갑옷 |
| 빠른 반복 | Warriors에는 batch painting 가능 |

## Difficulty

Intermediate. 금속색은 칠하기 쉽지만, **wash 조절**이 어렵습니다. 한 번에 진하게 넣으면 갑옷 전체가 탁한 회색이 됩니다.

## Preparation

1. 갑옷 판의 몰드라인을 제거합니다. **밝은 금속에서는 몰드라인이 훨씬 잘 보입니다.**
2. 프라이머가 모든 홈에 들어갔는지, 표면이 거칠지 않은지 확인합니다.
3. 회색 플라스틱이 비치는 곳을 `Gunmetal`로 보수합니다.
4. 천, 털, 가죽이 될 부위는 `Black`으로 덮어 둡니다.
5. 마커는 갑옷 넓은 면에 쓰지 않습니다.

## Step-by-step workflow

1. `Gunmetal`을 프라이머가 얇게 올라간 부분과 보수 부위에 칠해 표면을 통일합니다.
2. `Game Wash Black`을 **묽게 두 번** 나눠 넣습니다. 판 경계, 리벳 주변, 겨드랑이, 무릎 안쪽에 집중합니다.
3. 한 번에 진하게 넣지 말고, 마른 뒤 부족한 곳만 다시 넣습니다.
4. `Agrax Earthshade + Seraphim Sepia`를 1:1로 섞어 **희석 없이 갑옷 전면**에 올립니다. 얼룩이 조금 남아야 오히려 이 느낌이 납니다.
   이 단계가 스킴의 정체입니다. 색 파츠가 거의 없는데도 전체가 황동빛으로 보이는 이유가 여기 있습니다.
5. `Chainmail Silver`를 판 중앙과 상단 면에 얇게 올려 갑옷 밝기를 결정합니다. 이 단계에서 처음 대비가 눈에 보입니다.
6. `Silver`로 어깨, 헬멧, 무릎, 정강이, 방패 상단 모서리를 **선으로** 긋습니다.
7. `Silver + Off White`를 아주 조금 섞어 헬멧 최상단과 어깨 극점에만 점으로 찍습니다.
8. 너무 밝아진 부분은 묽은 `Game Wash Black`으로 낮춥니다.

> ⚠ 2번과 5번 사이를 서두르지 마세요. wash가 완전히 마르기 전에 `Chainmail Silver`를 올리면 금속 입자가 wash를 끌고 다녀 얼룩이 생깁니다.

## 밝기 배분

| 부위 | 색 | 면적 |
|---|---|---:|
| 판 경계, 홈, 겨드랑이 | Game Wash Black | 20~30% |
| 판 전체 바탕 | Gunmetal | 100% (아래층) |
| 판 중앙과 상단 | Chainmail Silver | 40~60% |
| 모서리 | Silver | 5~10% |
| 극점 | Silver + Off White | 1~2% |

💡 Pro Tip  
`Chainmail Silver`를 **판의 위쪽 절반에만** 올린다고 생각하세요. 아래쪽 절반을 `Gunmetal`로 남겨 두는 것만으로 판이 입체적으로 보입니다.

## Marker Tips

갑옷 큰 면에는 마커를 권장하지 않습니다. Pale Steel은 표면이 밝아서 마커의 스트로크와 광택 차이가 **어두운 갑옷 스킴보다 훨씬 잘 보입니다.**

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| Armor trim 초벌 | 권장 | 양각 장식만 빠르게 |
| Rivets | 강력 추천 | 반복 점 작업 |
| Chains | 권장 | 사슬 돌출부 초벌 |
| Battle chips | 제한적 | 작은 손상점 |
| Large plates | 절대 비추천 | 펜 자국과 광택 차이 |

## Professional tips

💡 Pro Tip

밝은 갑옷에서 하이라이트를 더 올리고 싶어질 때, 대부분 필요한 것은 **더 어두운 홈**입니다. `Silver`를 추가하기 전에 `Game Wash Black`을 판 경계에 한 번 더 넣어 보세요.

💡 Pro Tip

Chaos Lord는 같은 레시피에서 `Silver` 엣지를 한 단계 더 촘촘하게, Chaos Warriors는 한 단계 성기게 두면 계급 차이가 자연스럽게 생깁니다.

💡 Pro Tip

무광 바니시를 전체에 뿌리면 금속이 회색 플라스틱처럼 죽습니다. **금속에는 Satin, 천과 털에는 Matt**을 따로 적용하세요.

## Common mistakes

- `Game Wash Black`을 한 번에 진하게 넣어 갑옷이 탁한 회색이 되는 것
- `Silver`를 면으로 칠해 갑옷이 알루미늄 호일처럼 보이는 것
- Sepia를 아껴 써서 갑옷이 차가운 은색 그대로 남는 것 — 이 스킴은 **황동빛이 나야** 맞습니다
- Wash가 마르기 전에 금속 레이어를 올려 얼룩이 생기는 것
- 무기까지 갑옷과 같은 밝기로 칠해 재질이 구분되지 않는 것
- 몰드라인을 남긴 채 밝은 금속을 올리는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 갑옷이 밋밋하다 | 홈이 얕음 | `Game Wash Black`을 판 경계에 추가 |
| 갑옷이 탁한 회색이다 | Wash 과다 | `Chainmail Silver` 재레이어 후 묽게 재작업 |
| 갑옷이 호일 같다 | Silver 면적 과다 | 묽은 Black Wash로 낮추고 엣지만 남김 |
| 금속이 너무 누렇다 | Sepia 과다 | `Chainmail Silver`로 판 중앙만 되살림 |
| 금속이 차갑고 밋밋하다 | Sepia 부족 | Agrax + Sepia 1:1을 전면에 한 번 더 |
| Wash에 테두리가 남았다 | 한 번에 진하게 | 해당 면 재레이어 후 묽게 2회 |
| 갑옷이 회색 플라스틱 같다 | 무광 과다 | Satin Varnish를 금속에만 적용 |

## Summary

밝은 강철 갑옷은 이 Spearhead의 중심입니다. **판 중앙을 밝히기 전에 판 경계를 어둡게 만드세요.** 갑옷이 밝을수록 [Bronze Recipe](bronze.md)와 [Cloth Recipe](cloth.md)의 어두운 색이 더 잘 살아납니다.
