# Steel

![Steel Weapons and Chains](../images/steel-weapons-01.jpg)

## Introduction

Steel은 무기, 사슬, 리벳, 갑옷 손상점에 사용합니다. **Pale Steel** 스킴에서는 갑옷이 이미 밝은 금속이기 때문에, 무기까지 같은 밝기로 칠하면 **모델 전체가 하나의 은색 덩어리**로 보입니다.

이 레시피의 핵심은 단 하나입니다. **무기는 갑옷보다 한 단계 어둡게.** 갑옷이 닦아 관리하는 판금이라면, 무기는 피와 흙을 뒤집어쓴 도구입니다. 날 끝만 위험하게 밝으면 충분합니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 갑옷과 분리 | 갑옷보다 어둡고 채도가 낮게 |
| 청동과 분리 | 청동보다 차갑게 |
| 무기 날 강조 | 끝과 날 선만 밝게 |
| 사슬 빠른 처리 | 마커와 wash 조합 |
| 과한 반짝임 방지 | Silver는 날 선과 극점에만 |

## Difficulty

Beginner to Intermediate. 무기 날의 edge highlight는 연습이 필요하지만 사슬과 리벳은 비교적 빠르게 처리할 수 있습니다.

## 갑옷과 무기의 밝기 차이

| 부위 | 최종 밝기 | 방법 |
|---|---|---|
| 갑옷 판 상단 | 가장 밝음 | Chainmail Silver 넓게 |
| 무기 날 면 | 중간 | Chainmail Silver를 날 면에만 |
| 무기 날 선 | 밝음 (선만) | Silver 한 줄 |
| 사슬, 리벳 | 중간~어두움 | Gunmetal + Silver 점 |
| 무기 손잡이 금속 | 가장 어두움 | Gunmetal + Sepia Wash |

💡 Pro Tip  
무기를 갑옷과 구분하는 가장 쉬운 방법은 **Black Wash를 한 번 더 넣는 것**입니다. 색을 바꿀 필요 없이 같은 `Gunmetal`을 쓰면서도 재질이 분리됩니다.

## Preparation

1. 무기와 사슬은 조립 전에 칠하는 편이 훨씬 쉽습니다.
2. 날의 몰드라인을 제거합니다. 날 선에 몰드라인이 남으면 하이라이트가 두 줄로 보입니다.
3. 갑옷 작업이 끝난 뒤 무기를 칠해 밝기를 직접 비교합니다.
4. 금속 전용 붓과 물컵을 사용합니다.

## Step-by-step workflow

1. 무기 전체에 `Game Wash Black`을 한 번 넣어 갑옷보다 기준을 낮춥니다.
2. `Gunmetal`을 날과 금속 부위에 얇게 올립니다.
3. `Game Wash Black`을 홈, 날 뿌리, 사슬 사이에 다시 넣습니다.
4. 손잡이 금속과 사슬 몇 곳에 `Sepia Wash`를 점으로 넣어 때를 만듭니다.
5. `Chainmail Silver`를 **날 면에만** 올립니다. 손잡이와 사슬에는 올리지 않습니다.
6. `Silver`로 날 선을 한 줄 긋고, 날 끝과 리벳 상단에 점을 찍습니다.
7. 필요하면 날에 아주 얇은 스크래치를 `Silver`로 몇 개만 추가합니다.

## Marker Tips

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| Rivets | 강력 추천 | 반복 점 작업 |
| Chains | 강력 추천 | 돌출부만 빠르게 |
| 무기 날 면 | 제한적 | 스트로크가 남기 쉬움 |
| 날 선 | 비추천 | 얇은 선은 붓이 정확함 |
| 손잡이 가죽/나무 | 비추천 | 재질감이 사라짐 |

> ⚠ 사슬은 마커의 최고 활용처입니다. `Dark Aluminium` 마커로 돌출부만 찍은 뒤 `Game Wash Black`을 흘리면 몇 분 만에 끝납니다.

## Professional tips

💡 Pro Tip

날 선 하이라이트는 **끊어서** 긋습니다. 한 줄로 완벽하게 이으면 장난감처럼 보이고, 두세 번 끊어 그으면 벼려진 날처럼 보입니다.

💡 Pro Tip

스크래치는 날 전체에 흩뿌리지 말고, **날 뿌리 쪽에 몇 개만** 넣으세요. 실제로 부딪히는 부분이 그곳입니다.

💡 Pro Tip

무기가 갑옷보다 밝아졌다면 무기를 어둡게 하는 대신 갑옷을 밝히고 싶어지지만, 그러면 모델 전체가 하얗게 날아갑니다. 항상 **어두운 쪽을 조정**하세요.

## Common mistakes

- 무기를 갑옷과 같은 밝기로 칠해 재질이 구분되지 않는 것
- `Chainmail Silver`를 손잡이와 사슬까지 올려 전체가 은색이 되는 것
- 날 선을 두껍게 그어 무기가 두꺼워 보이는 것
- 스크래치를 날 전체에 흩뿌리는 것
- 금속 붓을 다른 색과 공유해 천에 반짝임이 남는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 무기가 갑옷에 묻힌다 | 밝기 차이 부족 | 무기에 `Game Wash Black` 1회 추가 |
| 날이 밋밋하다 | 날 면 레이어 부족 | `Chainmail Silver`를 날 면에만 추가 |
| 날 선이 두껍다 | 도료량 과다 | `Gunmetal`로 선 폭 줄이기 |
| 사슬이 뭉쳐 보인다 | 홈 그림자 부족 | `Game Wash Black`을 사슬 사이에 |
| 녹이 지저분하다 | 글레이즈 과다 | `Gunmetal`로 복구 후 점으로만 |

## Summary

Pale Steel에서 무기의 역할은 **갑옷을 돋보이게 하는 어두운 금속**입니다. 같은 `Gunmetal`을 쓰되 wash를 한 번 더 넣어 기준을 낮추고, 날 선에만 `Silver`를 남기세요. 따뜻한 금속은 [Bronze Recipe](bronze.md)에서 분리합니다.

## Checklist

- [ ] 무기 전체에 Black Wash를 한 번 더 넣어 기준을 낮췄다.
- [ ] `Chainmail Silver`를 날 면에만 올렸다.
- [ ] 날 선 하이라이트를 끊어서 그었다.
- [ ] 사슬과 리벳은 마커로 빠르게 처리했다.
- [ ] 갑옷과 무기를 나란히 두고 밝기를 비교했다.
