# Cloth

![Dark Cloth](../images/cloth-dark-01.jpg)

## Introduction

Slaves to Darkness의 천은 갑옷과 금속 사이에서 어두운 색 포인트를 제공합니다. 이 책은 두 가지 선택을 제안합니다. 붉은 천은 피와 의식의 느낌을 주고, 보라 천은 더 귀족적이고 마법적인 분위기를 줍니다. 어느 쪽이든 큰 면을 너무 밝게 칠하지 않는 것이 중요합니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 어두운 포인트 | 갑옷보다 살짝 색이 보이는 정도 |
| 부드러운 주름 | 금속처럼 날카롭지 않게 |
| 전군 통일 | 붉은 천 또는 보라 천 중 하나 선택 |
| 마커 비추천 | 큰 천은 붓 레이어가 우월 |

## Difficulty

Intermediate. 주름 방향을 읽고 얇은 레이어를 쌓아야 합니다.

## Preparation

1. 천이 갑옷과 금속에 가려지는 부분을 확인합니다.
2. 망토가 큰 모델은 서브어셈블리를 고려합니다.
3. 마커는 큰 천 면에 사용하지 않습니다.
4. 전군 포인트 색을 Red 또는 Purple 중 하나로 정합니다.

## Step-by-step workflow

1. Gory Red 또는 Hexed Lichen을 천 전체에 얇게 2회 칠합니다.
2. Black Wash를 주름 골에 넣습니다.
3. 기준색과 layer 색을 섞어 주름 산을 밝힙니다.
4. 가장 높은 주름에 Bloody Red 또는 Royal Purple을 좁게 올립니다.
5. 캐릭터는 아주 소량의 Bonewhite를 섞어 극점만 찍습니다.
6. 필요하면 기준색 glaze로 전체를 다시 통일합니다.

## Marker Tips

Large cloth는 마커 비추천입니다. 천은 주름 방향에 따라 색이 부드럽게 변해야 하는데, 마커는 일정한 폭과 잉크량 때문에 경계가 남기 쉽습니다.

마커가 허용되는 천 관련 작업은 매우 제한적입니다.

| 작업 | 마커 사용 | 이유 |
|---|---|---|
| 작은 찢어진 끝단의 어두운 오염 | 제한적 | Chipping Color 점 작업 |
| 천 위 금속 symbol | 권장 | symbol은 천이 아니라 장식 |
| 큰 망토 base | 비추천 | 펜 자국이 남음 |
| 주름 highlight | 비추천 | 붓의 압력 조절이 필요 |

> ⚠ 천을 마커로 칠하면 빠르게 덮일 수는 있지만, 주름의 부드러운 명암이 사라집니다. 붓으로 얇게 여러 번 칠하는 편이 훨씬 고급스럽습니다.

## Professional tips

💡 Pro Tip

붉은 천은 너무 밝게 올리면 Khorne 느낌이 강해집니다. Slaves to Darkness 공통 스킴에서는 어두운 붉은색을 유지하는 편이 더 범용적입니다.

💡 Pro Tip

보라 천은 Chaos Lord에 특히 잘 어울립니다. 하지만 Warriors 전체에 쓰면 스킴이 차가워지므로 bronze를 조금 더 따뜻하게 유지하세요.

## Common mistakes

- 천을 갑옷보다 밝게 만들어 시선이 분산되는 것
- 드라이브러시로 큰 망토를 칠해 표면이 거칠어지는 것
- 마커로 주름을 그어 펜 선이 남는 것
- 주름 골과 산의 방향을 무시하는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 천이 너무 밝다 | highlight 과다 | 기준색 glaze로 낮춤 |
| 천이 검게만 보임 | layer 부족 | 주름 산에 한 단계 밝은 색 추가 |
| 붓자국이 보임 | 도료가 진함 | 물/medium으로 묽게 여러 번 |
| 하단 오염이 과함 | brown glaze 과다 | 기준색으로 일부 복구 |

## Summary

천은 어두운 군대에 색을 주는 조연입니다. 큰 천은 마커보다 붓이 우월하며, [Armor Recipe](armor.md)와 [Bronze Recipe](bronze.md)를 방해하지 않는 낮은 밝기로 유지하세요.
