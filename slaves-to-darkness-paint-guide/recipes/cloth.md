# Cloth

![Dark Cloth](../images/cloth-dark-01.jpg)

## Introduction

**Pale Steel** 스킴에서 천은 모델의 **유일한 색 포인트**입니다. 갑옷, 무기, 청동, 사슬이 모두 금속이기 때문에, 배너와 망토의 붉은색이 없으면 모델이 온통 은색으로만 읽힙니다.

기준색은 **채도를 낮춘 짙은 핏빛 적색**입니다. 선명한 빨강은 은색 옆에서 지나치게 튀어 갑옷을 이겨버립니다. 어둡고 낮은 채도로 두어야 갑옷이 주인공으로 남으면서도 시선이 배너로 한 번 흐릅니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 유일한 색 포인트 | 은색 사이에서 눈이 쉬는 곳 |
| 낮은 채도 | 갑옷보다 튀지 않을 것 |
| 부드러운 주름 | 금속처럼 날카롭지 않게 |
| 전군 통일 | 모든 모델이 같은 적색 |
| 배너 문양 | 크림색 문양으로 대비 |

## Difficulty

Intermediate. 주름 방향을 읽고 얇은 레이어를 쌓아야 합니다. 배너처럼 넓고 평평한 면은 특히 붓 자국이 남기 쉽습니다.

## Tools

## Preparation

1. 천이 될 부위를 `Black`으로 덮어 금속 입자를 차단합니다.
2. 주름의 골과 산이 어디인지 눈으로 먼저 확인합니다.
3. 배너는 조립 전에 칠하는 편이 훨씬 편합니다.
4. 문양을 그릴 예정이면 그 자리에 `Off White` 밑칠을 준비합니다.
5. 천 브러시는 금속 도료에 쓰지 않은 것을 사용합니다.

## Step-by-step workflow

1. `Charred Brown`을 천 전체에 칠해 어두운 바탕을 만듭니다.
2. `Gory Red`를 주름 산과 넓은 면에 얇게 2회 올립니다. 골에는 `Charred Brown`이 남게 둡니다.
3. `Game Wash Black`을 골에만 흘려 정리합니다. 오래된 천 느낌을 원하면 `Sepia Wash`를 씁니다.
4. `Gory Red`로 주름 산을 다시 복구합니다.
5. `Gory Red + Bonewhite`를 소량 섞어 주름 상단과 천 가장자리에 얇게 올립니다.
6. 캐릭터 모델에만 `Bonewhite`를 조금 더 섞어 극점을 찍습니다.
7. 배너 문양은 `Off White`로 밑칠한 뒤 `Bonewhite`로 정리합니다.

💡 Pro Tip  
배너 문양은 한 번에 그리려 하지 마세요. **연필로 옅게 밑그림**을 그리고, `Off White`로 채운 뒤 `Bonewhite`로 정리하면 훨씬 깔끔합니다. 틀린 부분은 `Gory Red`로 덮고 다시 시작하면 됩니다.

## Marker Tips

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| 배너 문양 밑칠 | 제한적 권장 | Off White 마커로 형태만 |
| 천 가장자리 손상 | 제한적 | 찢어진 끝단 |
| 큰 천 면 | 비추천 | 펜 자국과 경계가 그대로 남음 |
| 주름 하이라이트 | 비추천 | 부드러운 전이가 필요 |

> ⚠ 천은 이 책에서 마커를 가장 권하지 않는 부위입니다. 붓 레이어가 압도적으로 우월합니다.

## Professional tips

💡 Pro Tip

붉은 천이 튀어 보인다면 채도를 낮추세요. `Charred Brown`을 아주 묽게 만들어 천 전체에 한 번 글레이즈하면 색은 유지되면서 갑옷과의 싸움이 사라집니다.

💡 Pro Tip

천의 하이라이트에 흰색을 섞으면 분홍빛이 돕니다. 흰색 대신 **`Bonewhite`(크림색)** 를 섞으면 낡은 천처럼 따뜻하게 밝아집니다.

💡 Pro Tip

배너 아래쪽 20%를 `Charred Brown`으로 더 어둡게 두면, 배너가 실제로 바닥에서 그늘져 있는 것처럼 보입니다.

## Common mistakes

- 금속 프라이머 위에 바로 붉은색을 칠해 천이 반짝이는 것
- 선명한 빨강을 써서 갑옷보다 천이 먼저 보이는 것
- 하이라이트에 흰색을 섞어 분홍빛이 도는 것
- 주름 골까지 밝게 칠해 천이 평평해 보이는 것
- 문양을 한 번에 그리려다 배너 전체를 다시 칠하게 되는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 천이 반짝인다 | 금속 입자 혼입 | `Black` 덮고 재도색 |
| 천이 갑옷보다 튄다 | 채도 과다 | `Charred Brown` 글레이즈 |
| 천이 평평하다 | 골 그림자 부족 | `Game Wash Black`을 골에만 |
| 하이라이트가 분홍이다 | 흰색 혼합 | `Bonewhite` 혼합으로 재작업 |
| 붓 자국이 남는다 | 도료가 두꺼움 | 습식 팔레트에서 얇게 여러 번 |

## Summary

천은 은색 군대에서 **유일하게 색을 가진 부위**입니다. 어둡고 채도가 낮은 적색으로 두어 갑옷을 이기지 않게 하고, 배너 문양만 크림색으로 밝혀 시선을 한 번 잡아 주세요.

## Checklist

- [ ] 천 부위를 `Black`으로 덮은 뒤 시작했다.
- [ ] `Charred Brown`으로 어두운 바탕을 만들었다.
- [ ] 주름 골에 `Charred Brown`을 남겼다.
- [ ] 하이라이트에 흰색 대신 `Bonewhite`를 섞었다.
- [ ] 전군이 같은 적색을 쓰기로 했다.
- [ ] 천은 Matt으로 마감하기로 했다.
