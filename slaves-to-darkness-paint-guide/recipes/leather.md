# Leather

![Leather Straps](../images/leather-straps-01.jpg)

## Introduction

Leather는 벨트, 스트랩, 무기 손잡이, Chaos Knights의 안장과 고삐에 사용합니다. Slaves to Darkness의 가죽은 깨끗한 새 가죽보다 닳고 어두운 전투 장비처럼 보여야 합니다. 갑옷과 trim의 대비를 방해하지 않도록 낮은 채도와 작은 하이라이트가 핵심입니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 낮은 채도 | 주인공은 갑옷과 trim |
| 사용감 | 손잡이와 벨트에 작은 마모 |
| 빠른 초벌 | brown marker 사용 가능 |
| 과한 밝기 방지 | Bonewhite는 작은 긁힘에만 |

## Difficulty

Beginner. 작은 면이 많아 수정이 쉽고, 마커 초벌도 비교적 안전합니다.

## Preparation

1. leather와 cloth를 구분합니다. 색이 비슷하면 나중에 둘 다 뭉쳐 보입니다.
2. 무기 손잡이는 steel을 칠하기 전에 가죽을 칠해도 좋습니다.
3. Knights 안장은 기수와 말 사이 접근성을 확인합니다.
4. 마커를 쓸 경우 brown이 너무 밝지 않은지 Black primer 위에서 확인합니다.

## Step-by-step workflow

1. Charred Brown을 leather 전체에 칠합니다.
2. 마커를 쓸 경우 Dark Brown 또는 Leather Brown marker로 초벌만 합니다.
3. Sepia Wash를 홈과 접합부에 넣습니다.
4. Leather Brown을 중앙 면과 손이 닿는 부분에 올립니다.
5. Khaki로 strap 엣지와 손잡이 모서리를 얇게 긋습니다.
6. Bonewhite를 아주 작은 긁힘에만 사용합니다.

## Marker Tips

Leather는 마커 초벌이 유용한 부위입니다. 특히 Knights의 고삐와 큰 안장 아래쪽처럼 반복되는 brown 면은 마커로 빠르게 덮을 수 있습니다.

| 부위 | 마커 사용 | 이유 |
|---|---|---|
| Weapon grip | 권장 | 작은 반복 면 |
| Belts/straps | 권장 | 선형 부위에 빠름 |
| Saddle underside | 권장 | 넓지만 거칠어도 자연스러운 부위 |
| Display leather highlight | 비추천 | 붓의 얇은 선이 더 좋음 |
| Skin | 절대 비추천 | 피부와 가죽의 색 변화는 다름 |

> ⚠ 가죽 마커 색이 너무 밝으면 모델 전체가 갈색 장비처럼 보입니다. 초벌 후 Sepia Wash나 Charred Brown glaze로 반드시 낮추세요.

## Professional tips

💡 Pro Tip

손잡이는 완벽한 직선보다 짧고 끊어진 하이라이트가 더 자연스럽습니다. 실제로 감긴 가죽은 빛이 일정하게 이어지지 않습니다.

💡 Pro Tip

Chaos Knights의 안장은 보이지 않는 부분이 많습니다. 보이는 상단과 외곽에만 시간을 집중하세요.

## Common mistakes

- 가죽을 너무 밝게 칠해 천과 경쟁하게 만드는 것
- 모든 leather strap에 같은 밝기의 하이라이트를 넣는 것
- 마커 초벌 후 wash 없이 그대로 두는 것
- 손잡이 홈에 도료를 두껍게 쌓는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 가죽이 너무 주황색 | Leather Brown 과다 | Charred Brown glaze |
| 가죽이 갑옷에 묻힘 | 경계 부족 | Black lining 추가 |
| 하이라이트가 두꺼움 | 브러시 도료량 과다 | Charred Brown으로 폭 줄임 |
| 마커 자국이 보임 | 넓은 면 단일 방향 | 붓 glaze로 통일 |

## Summary

Leather는 작지만 모델을 현실감 있게 만듭니다. 마커는 초벌에 유용하지만, 최종 깊이와 마모는 붓으로 완성하세요. Knights의 leather는 [Chaos Knights](../units/chaos-knights.md)에서 더 자세히 적용합니다.

- [ ] Khaki/Bonewhite 하이라이트가 과하지 않다.
