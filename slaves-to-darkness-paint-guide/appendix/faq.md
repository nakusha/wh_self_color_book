## Preparation

1. 질문이 생기면 먼저 기준 모델과 비교합니다.
2. 실제 게임 거리에서 보이는지 확인합니다.
3. 사진은 조명에 따라 달라지므로 눈으로도 확인합니다.
4. 전체 분대에 적용하기 전 한 모델에서 테스트합니다.

## Step-by-step workflow

1. 문제를 하나만 선택합니다.
2. 관련 recipe 장으로 돌아갑니다.
3. 테스트 카드 또는 기준 모델의 보이지 않는 곳에서 수정합니다.
4. 결과가 좋으면 분대 전체에 같은 방식으로 적용합니다.
5. 수정 후 사진과 도료 비율을 기록합니다.

## Marker Tips

**Q. 마커를 꼭 사야 하나요?**  
아닙니다. 이 책의 모든 레시피는 brush-only method로 완성할 수 있습니다. 마커는 trim, rivets, chains를 빠르게 처리하는 선택 도구입니다.

**Q. 마커로 갑옷을 칠해도 되나요?**  
넓은 갑옷 면에는 권장하지 않습니다. 검은 큰 면은 스트로크와 광택 차이가 잘 보이기 때문입니다.

**Q. 마커가 가장 좋은 부위는 어디인가요?**  
Armor trim 초벌, bronze trim, steel rivets, chains, shield symbols, small horn tips입니다.

**Q. 마커를 쓰면 붓 하이라이트가 필요 없나요?**  
필요합니다. 마커는 빠른 basecoat이고, 최종 깊이와 선명도는 wash와 brush highlight에서 나옵니다.

> ⚠ 얼굴과 피부에는 마커를 쓰지 마세요. 작은 면처럼 보여도 피부는 미묘한 색 변화가 필요해서 마커의 균일한 잉크가 부자연스럽습니다.

## Professional tips

💡 Pro Tip

강철 갑옷이 밋밋하게 느껴지면 `Silver`를 넓히지 말고, 판 경계에 `Game Wash Black`을 한 번 더 넣으세요.

💡 Pro Tip

Spearhead는 작은 게임 포맷이라 각 모델이 자주 손에 잡힙니다. 바니시를 생략하지 마세요.

## Common mistakes

- FAQ 답을 모든 모델에 바로 적용하는 것
- 마커를 편하다는 이유로 모든 재질에 쓰는 것
- 사진에서 밝게 보이려고 실제 모델을 과하게 하이라이트하는 것
- Chaos Lord와 Warriors를 같은 밝기로 칠하는 것

## Troubleshooting

| 질문 | 짧은 답 |
|---|---|
| 먼저 뭘 칠하나요? | Chaos Warrior 기준 모델 |
| 에어브러시가 필요한가요? | 아니요, Knights 큰 면에만 유용합니다 |
| 마커가 필요한가요? | 필수는 아니지만 rivets/trim에 편합니다 |

| 천은 무슨 색이 좋나요? | Gory Red 또는 Hexed Lichen 중 하나 |
| 베이스는 밝게 해도 되나요? | 모델보다 튀지 않을 정도만 |

## Summary

대부분의 질문은 기준 모델, 테스트 카드, 부위별 recipe로 해결됩니다. 마커는 빠른 보조 도구이며, 최종 품질은 붓 정리와 정확한 명도에서 나옵니다.

## Checklist

- [ ] 질문을 관련 recipe와 연결했다.
- [ ] 한 모델에서 먼저 테스트했다.
- [ ] 마커를 필수 도구로 생각하지 않는다.
- [ ] 강철 갑옷은 판 경계의 어둠부터 수정한다.
- [ ] 수정 결과를 기록했다.
