# Paint Alternatives

![Paint Alternatives](../images/paint-alternatives-01.jpg)

## Introduction

이 장은 책 전체에서 사용한 색의 브랜드별 대체표입니다. 대체색은 완전한 복제가 아니라 같은 역할을 수행하는 색입니다. 중요한 것은 병 이름보다 `Basecoat`, `Layer`, `Shade`, `Highlight`의 역할입니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 브랜드 유연성 | 가진 도료로 레시피 재현 |
| 색 역할 유지 | 명도와 온도 우선 |
| 마커 호환 | 마커는 작업 대체로 이해 |
| 전군 통일 | 같은 부위는 같은 기준 유지 |

## Difficulty

Beginner to Intermediate. 실제 테스트 카드 없이 대체색을 고르면 결과가 흔들릴 수 있습니다.

## Preparation

1. 같은 primer 위에서 비교합니다.
2. 대체색은 단독 색이 아니라 shade와 highlight까지 함께 테스트합니다.
3. 금속은 varnish 후 광택을 반드시 비교합니다.
4. 마커는 실제 사용할 작은 부위 크기로 테스트합니다.

## Step-by-step workflow

1. 기준 Vallejo 색을 카드 왼쪽에 칠합니다.
2. 대체 브랜드 색을 오른쪽에 칠합니다.
3. 같은 wash를 적용합니다.
4. 같은 varnish를 적용합니다.
5. 실제 모델 거리에서 명도와 온도를 비교합니다.
6. 전군에 사용할 대체색을 기록합니다.

## Conversion recipe

| Stage | Paint | Purpose |
|---|---|---|
| Primer | 동일 Black Primer | 비교 기준 |
| Basecoat | 후보 base color | 기본 명도 |
| Layer | 후보 layer color | 상승 폭 |
| Shade | 동일 wash | 반응 비교 |
| Highlight | 후보 highlight | edge 밝기 |
| Edge Highlight | 동일 white/bone mix | 극점 통일 |
| Optional Drybrush | 동일 light grey | 질감 비교 |
| Optional Weathering | 동일 Chipping Color | 오염 반응 |
| Brush-only method | 같은 희석비 | 커버력 비교 |
| Airbrush notes | 같은 thinner 비율 | 분사성 비교 |
| Recommended varnish | 같은 Matt/Satin | 최종 색 비교 |

## Marker Tips

| 작업 | AK Interactive marker | 붓 도료 대체 | 사용 방식 |
|---|---|---|---|
| Rivets | Aluminium, Dark Aluminium | Dark Gunmetal, Silver | 찍고 wash |
| Chains | Aluminium | Dark Gunmetal | 초벌 후 Black Wash |
| Bronze trim | Brown/Bronze 계열 제품 가용 시 | Tinny Tin, Brassy Brass | 초벌 후 brush highlight |
| Shield symbol | Off White, Aluminium | Bonewhite, Tinny Tin | 밑칠 또는 금속 초벌 |
| Horn tip | Off White | Bonewhite | 밑칠 후 glaze |
| Chipping | Chipping Color | Charred Brown | 작은 점만 |

> ⚠ 마커 대체표는 색상 대체표가 아니라 작업 대체표입니다. 마커는 빠르게 칠하는 도구이고, 최종 색 일치는 붓 레이어와 wash로 맞춥니다.

## Professional tips

💡 Pro Tip

대체색이 완전히 같지 않아도 괜찮습니다. 전군 안에서 같은 부위에 같은 대체색을 반복하면 통일감은 유지됩니다.

💡 Pro Tip

금속 대체색은 색보다 입자 크기와 광택이 더 중요합니다. 거친 금속 도료는 작은 trim을 뭉치게 만듭니다.

## Common mistakes

- 병 색만 보고 대체색을 선택하는 것
- Black primer 위 발색을 확인하지 않는 것
- 마커를 흰 카드에서만 테스트하는 것
- 같은 유닛 안에서 base color를 여러 브랜드로 섞는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 대체색이 너무 밝다 | 명도 차이 | wash/glaze로 낮춤 |
| 대체색이 너무 탁하다 | 채도 부족 | highlight 색을 조금 밝게 |
| 금속 질감이 다름 | 입자/광택 차이 | varnish와 edge로 통일 |
| 마커가 튐 | 색 역할 불일치 | 붓 base로 일부 덮기 |

## Summary

대체 도료는 같은 역할을 수행하면 충분합니다. Vallejo Game Color를 기준으로 삼되, 보유한 Citadel, AK Interactive, Army Painter, Two Thin Coats 도료를 역할별로 대응시키세요.
