# Common Mistakes

![Common Mistakes](../images/common-mistakes-01.jpg)

## Introduction

Slaves to Darkness 도색의 실수는 대부분 색 선택보다 명도, 순서, 도료 두께, 마커 사용 위치에서 생깁니다. 검은 갑옷은 너무 어두우면 안 보이고, 너무 밝으면 검은 갑옷이 아닙니다. 마커는 trim과 rivets에는 빠르지만, 넓은 면과 자연 재질에는 위험합니다.

## Painting goals

| 목표 | 설명 |
|---|---|
| 문제를 빠르게 진단 | 표면, 색, 마감, 도구 문제 분리 |
| 복구 가능성 유지 | 젖은 도료를 계속 만지지 않음 |
| 전군 통일 회복 | 기준 모델로 돌아가기 |
| 마커 실수 처리 | 완전 건조 후 붓으로 복구 |

## Difficulty

Beginner to Advanced. 작은 실수는 쉽게 고칠 수 있지만, 프라이머와 바니시는 예방이 가장 중요합니다.

## Preparation

1. 문제 부위를 확대 사진으로 확인합니다.
2. 표면 문제인지 색 문제인지 먼저 구분합니다.
3. 젖은 도료는 억지로 문지르지 않습니다.
4. 마커 실수는 완전히 마른 뒤 복구합니다.
5. 기준 모델과 비교해 어느 단계가 달라졌는지 찾습니다.

## Step-by-step workflow

1. 실수를 발견하면 멈추고 건조를 기다립니다.
2. 갑옷 번짐은 Black 또는 Charcoal로 경계를 다시 그립니다.
3. trim이 탁하면 Brassy Brass로 상단을 복구합니다.
4. steel이 너무 밝으면 Black Wash로 낮춥니다.
5. 마커 번짐은 주변 base color로 덮고 다시 작은 면만 칠합니다.
6. 바니시 문제는 테스트 카드에서 복구 방법을 확인한 뒤 모델에 적용합니다.

## Recovery recipe

| Stage | Paint | Purpose |
|---|---|---|
| Primer | 필요 시 부분 Black Primer | 표면 복구 |
| Basecoat | Black, Charcoal | 갑옷 복구 |
| Layer | Tinny Tin, Dark Gunmetal | 금속 복구 |
| Shade | Black Wash, Sepia Wash | 톤 재정리 |
| Highlight | Neutral Grey, Brassy Brass, Silver | 읽힘 복구 |
| Edge Highlight | Bonewhite mix, Silver point | 극점 복구 |
| Optional Drybrush | Neutral Grey | 베이스 복구 |
| Optional Weathering | Chipping Color | 작은 흠 숨김 |
| Brush-only method | 얇은 glaze와 edge 수정 | 가장 안전 |
| Airbrush notes | 큰 면만 얇은 필터 | 고급 복구 |
| Recommended varnish | 테스트 후 재마감 | 최종 보호 |

## Marker Tips

| 실수 | 원인 | 해결 |
|---|---|---|
| 마커가 흘러내림 | 모델 위 펌핑 | 완전 건조 후 base color로 덮기 |
| 점이 너무 큼 | 팁 크기 과다 | 주변 색으로 점 크기 줄이기 |
| 광택이 다름 | 마커 표면 광택 | Matt/Satin test 후 통일 |
| 색이 너무 선명 | 밝은 밑칠 위 과발색 | wash로 낮추기 |

마커 실수는 젖은 상태에서 닦으려 하면 더 넓게 번질 수 있습니다. 특히 metal marker는 입자가 주변 갑옷에 퍼지기 쉬우므로 건조 후 덮는 방식이 안전합니다.

> ⚠ 마커 실수를 웨더링으로 무조건 숨기지 마세요. 손상이 있어야 할 위치가 아니면 더 부자연스럽습니다.

## Professional tips

💡 Pro Tip

대부분의 edge 실수는 "덮고 다시 긋기"로 해결됩니다. 선을 완벽하게 한 번에 그으려 하지 말고, Black으로 폭을 줄이며 조정하세요.

💡 Pro Tip

분대 전체가 너무 밝아졌다면 개별 모델을 수정하기보다 전체에 얇은 Black glaze를 같은 방식으로 적용하는 편이 통일감이 좋습니다.

## Common mistakes

- 젖은 도료를 계속 만져 표면을 찢는 것
- 검은 갑옷 복구에 순수 Black만 써 모든 명암을 지우는 것
- 마커 실수를 문질러 금속 입자를 퍼뜨리는 것
- 바니시를 테스트 없이 바로 모델에 뿌리는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 갑옷이 검은 덩어리 | edge 부족 | Neutral Grey edge 추가 |
| 갑옷이 회색 | highlight 과다 | Black glaze |
| bronze가 탁함 | wash 과다 | Brassy Brass 상단 복구 |
| fur가 거침 | drybrush 과다 | Sepia glaze |
| large cloth에 펜 자국 | 마커 사용 | 기준색 glaze 후 붓 layer |
| face가 부자연스러움 | 마커 사용 또는 과한 눈 | 붓으로 base 재정리 |

## Summary

실수는 대부분 복구 가능합니다. 중요한 것은 문제를 키우지 않는 것입니다. 멈추고, 말리고, 기준 색으로 돌아간 뒤 다시 얇게 쌓으세요.

## Checklist

- [ ] 문제를 표면/색/마감/도구 문제로 구분했다.
- [ ] 젖은 도료를 문지르지 않았다.
- [ ] 마커 실수는 완전 건조 후 복구했다.
- [ ] 기준 모델과 비교했다.
- [ ] 복구 후 바니시를 다시 테스트했다.
