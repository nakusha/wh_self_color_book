# 05 Brushes

![Brush Control](images/brushes-01.jpg)

## Introduction

Slaves to Darkness는 작은 장식이 많지만, 모든 작업을 작은 브러시로 할 필요는 없습니다. 좋은 브러시는 크기가 작은 브러시가 아니라 끝이 잘 모이고 도료를 적당히 머금는 브러시입니다. 마커가 trim 초벌을 빠르게 도와주더라도, 최종 shade, highlight, edge highlight는 붓이 담당해야 합니다.

## Painting goals

| 목표 | 브러시 선택 |
|---|---|
| 갑옷 basecoat | 1호 또는 2호 라운드 |
| trim 정리 | 1호 끝 또는 0호 |
| 리벳 점 | 0호 또는 마커 0.7mm |
| 털 드라이브러시 | 낡은 합성모 |
| 방패 문양 | 0호, 필요 시 마커 초벌 |

## Difficulty

Beginner to Intermediate. 브러시 제어는 손재주보다 도료 농도, 손 고정, 브러시 크기 선택의 문제입니다.

## Tools

- 2호 라운드 브러시: 넓은 갑옷과 방패
- 1호 라운드 브러시: 대부분의 레이어
- 0호 브러시: 리벳, 눈, 작은 문양
- 낡은 브러시: wash, pigment, glue
- 드라이브러시: 털과 베이스
- 브러시 비누
- 페이퍼 타월

## Preparation

1. 새 브러시는 보호 풀을 완전히 씻어냅니다.
2. 금속 도료용 브러시는 별도로 정합니다.
3. 브러시 털의 절반 이상까지 도료가 올라가지 않게 합니다.
4. 팔레트에서 브러시를 굴려 끝을 모은 뒤 모델에 가져갑니다.
5. 손목을 공중에 띄우지 말고 양손을 서로 기대어 고정합니다.

## Step-by-step workflow

1. 2호 또는 1호로 `Gunmetal` basecoat를 얇게 올립니다.
2. 1호 끝으로 trim 주변을 정리합니다.
3. 금속 trim은 마커 또는 브러시로 초벌 후, 0호로 경계 정리를 합니다.
4. `Silver` edge highlight는 브러시 끝보다 옆면을 사용해 긋습니다.
5. 털과 베이스는 드라이브러시로 질감 방향을 살립니다.
6. 작업 후 브러시 비누로 세척하고 끝을 모아 말립니다.

## Marker Tips

마커와 브러시는 경쟁 도구가 아닙니다. 마커는 빠른 초벌, 브러시는 정리와 깊이를 담당합니다.

| 부위 | 마커 먼저 | 브러시 마무리 |
|---|---|---|
| Armor trim | Tin/Bronze 계열 초벌 | Sepia Wash, Bright Bronze edge |
| Chains | Aluminium 초벌 | Black Wash, Silver point |
| Rivets | Steel dot | Black lining, Silver point |
| Shield symbols | Off White 또는 Bronze 초벌 | shade와 edge |
| Horns | Off White 끝단 밑칠 | Bonewhite glaze, brown bands |

Skin, faces, large cloth, fur는 마커보다 브러시가 우월합니다. 이 부위는 색을 단계적으로 얹거나 털 방향을 따라 질감을 만들어야 하며, 마커의 균일한 잉크 흐름은 자연스러운 변화에 맞지 않습니다.

> ⚠ 마커로 초벌한 trim도 그대로 끝내지 마세요. wash와 edge highlight가 들어가야 모델 전체와 같은 페인팅 언어가 됩니다.

## Professional tips

💡 Pro Tip

엣지 하이라이트가 두꺼워졌다면 당황하지 말고 `Gunmetal`로 선을 다시 좁히세요. 지우는 것이 아니라 모양을 재조각하는 과정입니다.

💡 Pro Tip

작은 브러시는 도료 저장량이 적어 오히려 선이 끊깁니다. 1호 브러시 끝이 좋다면 0호보다 안정적인 경우가 많습니다.

## Common mistakes

- 작은 모델은 무조건 000호로 칠해야 한다고 생각하는 것
- 도료가 브러시 페룰까지 올라가 끝이 갈라지는 것
- 마커 초벌 후 붓 정리를 생략하는 것
- 좋은 브러시로 드라이브러시를 하는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 선이 떨림 | 손목 고정 부족 | 양손을 서로 기대고 짧게 긋기 |
| 엣지가 두꺼움 | 도료량 과다 | 페이퍼 타월에 살짝 빼고 다시 |
| 금속 입자가 번짐 | 브러시 공유 | 금속 브러시 분리 |
| 드라이브러시가 분필 같음 | 도료가 너무 많음 | 더 많이 닦아낸 뒤 여러 번 |

## Summary

브러시는 이 프로젝트의 최종 품질을 결정합니다. 마커로 시간을 줄이고, 브러시로 형태와 깊이를 완성하세요. 다음 장 [Primer](06-primer.md)에서는 밝은 강철 갑옷의 basecoat를 겸하는 시작층을 다룹니다.
