# 03 Tools

![Painting Tools](images/tools-01.jpg)

## Introduction

도구는 도색 실력을 대신하지 않지만, 같은 실력을 더 안정적으로 반복하게 해줍니다. Slaves to Darkness Spearhead는 갑옷 trim, 사슬, 리벳, 방패 문양처럼 작은 금속 반복 작업이 많습니다. 그래서 브러시, 마커, 드라이브러시, 파일, 마스킹 도구를 역할별로 나누는 것이 중요합니다.

## Painting goals

| 목표 | 필요한 도구 | 이유 |
|---|---|---|
| 깨끗한 강철 갑옷 | 니퍼, 사포, 1호 브러시 | 표면 결함과 몰드라인이 밝은 금속에서 특히 잘 보임 |
| 빠른 trim 작업 | 0.7~1mm acrylic marker | 양각 금속 장식을 빠르게 초벌 |
| 거친 베이스 | 드라이브러시, 텍스처 도구 | 마른 흙 질감 표현 |
| 안정적 금속 | 금속 전용 브러시 | 금속 입자 오염 방지 |
| 대형 모델 명암 | 에어브러시 선택 | Chaos Knights의 큰 면 처리 |

Beginner. 도구를 많이 사는 것보다 어떤 도구를 어느 단계에 쓰는지 아는 것이 중요합니다.

## Preparation

1. 좋은 브러시와 금속 도료용 브러시를 분리합니다.
2. 마커는 모델에 쓰기 전 반드시 테스트 카드에서 잉크 흐름을 안정시킵니다.
3. 하비 나이프 칼날은 무뎌지면 바로 교체합니다.
4. 드라이브러시는 좋은 브러시를 쓰지 말고 낡은 합성모를 씁니다.
5. 에어브러시를 쓴다면 프라이머, basecoat, varnish용 세척 순서를 정합니다.

## Step-by-step workflow

1. 조립 전 모든 게이트 자국을 니퍼와 나이프로 정리합니다.
2. 갑옷 판은 사포로 가볍게 정리해 프라이머가 매끈하게 올라가게 합니다.
3. Black primer 후 표면 결함을 확인합니다.
4. 마커 테스트 카드에 Black primer, Grey primer, White primer 영역을 나눕니다.
5. 사용할 마커를 카드에 눌러보고 색, 흐름, 건조 시간을 기록합니다.
6. 실제 모델에는 작은 trim과 rivet부터 마커를 적용합니다.
7. 넓은 면, 피부, 털, 큰 천은 붓으로 처리합니다.

## Marker Tips

| 부위 | 추천 팁 | 마커가 빠른 이유 | 붓이 더 나은 경우 |
|---|---|---|---|
| Armor trim | 0.7~1mm | 양각 선을 따라가기 쉬움 | trim이 너무 얇거나 주변 갑옷이 이미 완성된 경우 |
| Bronze trim | 1mm | Tinny Tin 계열 초벌을 빠르게 넣음 | 최종 하이라이트 |
| Steel chains | 1mm | 돌출부를 빠르게 터치 | 깊은 사슬 안쪽 쉐이드 |
| Rivets | 0.7mm | 반복 점 작업에 빠름 | 리벳이 아주 작을 때 |
| Shields | 1mm | 방패 문양 초벌에 좋음 | 넓은 매끈한 방패 중앙 |
| Symbols | 0.7mm | 양각 문양 구분이 쉬움 | 음각 문양 워시 |
| Horns | 0.7mm | 끝단 밑칠에 좋음 | 그라데이션과 줄무늬 |

> ⚠ 마커로 피부, 얼굴, 큰 천, 털을 칠하지 마세요. 이 부위들은 색 변화와 방향성이 중요해서 마커의 일정한 잉크 흐름이 오히려 부자연스럽습니다.

## Professional tips

💡 Pro Tip

마커는 "완성 도구"보다 "초벌 속도 도구"로 생각하세요. 마커로 trim을 잡고, 붓으로 shade와 edge highlight를 넣으면 속도와 품질을 함께 얻을 수 있습니다.

💡 Pro Tip

금속 마커를 썼다면 바로 바니시하지 말고 하루 정도 건조시키세요. 표면이 마른 것처럼 보여도 내부가 충분히 굳지 않았을 수 있습니다.

## Common mistakes

- 모델 위에서 마커를 펌핑해 잉크가 흘러내리는 것
- 금속 브러시와 일반 브러시를 섞어 천과 뼈에 금속 입자가 묻는 것
- 좋은 브러시로 드라이브러시를 해서 끝이 망가지는 것
- 에어브러시를 세척하지 않아 다음 색에 이전 색이 섞이는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 마커가 갑자기 많이 나옴 | 모델 위에서 펌핑 | 테스트 카드에서 잉크를 빼고 붓으로 주변 정리 |
| 브러시 끝이 갈라짐 | 도료가 페룰까지 올라감 | 브러시 비누로 세척하고 용도 등급 낮춤 |
| 프라이머가 거침 | 거리/습도 문제 | 완전 건조 후 고운 사포로 정리 |
| 금속 입자가 갑옷에 묻음 | 물컵 공유 | 금속 전용 물컵과 브러시 분리 |

## Summary

도구의 핵심은 분업입니다. 브러시는 제어, 마커는 반복되는 작은 장식, 드라이브러시는 질감, 에어브러시는 큰 명암에 사용하세요. 다음 장 [Paints](04-paints.md)에서는 실제 색과 브랜드 대체표를 정리합니다.

- [ ] 마커 테스트 카드를 만들었다.
- [ ] 마커를 쓸 부위와 피할 부위를 정했다.
