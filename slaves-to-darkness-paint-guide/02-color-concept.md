## Introduction

Slaves to Darkness는 화려한 영웅 군대가 아니라, 어두운 강철과 저주받은 청동으로 전장을 밀고 들어오는 군대입니다. 이 책의 컬러 콘셉트는 `dark gunmetal`, `blackened iron`, `aged bronze`, `cold steel`, `dark cloth`, `dead earth`입니다. 색 수를 줄이고 재질 차이를 분명히 하면 초보자도 일관된 Spearhead를 만들 수 있습니다.

## Painting goals

| 색 영역 | 목표 | 왜 이 색인가 |
|---|---|---|
| Dark Gunmetal Armor | 검게 탄 금속 질감이 살아 있는 갑옷 | Slaves to Darkness의 상징적인 위압감 |
| Aged Bronze | 낡은 trim과 문양 | Chaos 장식의 고대성과 타락감 |
| Cold Steel | 무기와 사슬 | 전투 도구를 갑옷에서 분리 |
| Dark Cloth | 붉거나 보라 기운의 어두운 천 | 검은 갑옷에 귀족적 악의 포인트 |
| Dead Earth Base | 차갑고 낮은 채도 베이스 | 모델을 방해하지 않는 전장 분위기 |

## Difficulty

Beginner to Intermediate. 색 조합 자체는 단순하지만, 검정과 금속을 같은 밝기로 만들지 않는 판단이 필요합니다.

## Preparation

1. 같은 색을 Black primer와 Grey primer 위에 각각 칠합니다.
2. 금속 도료는 무광 바니시와 새틴 바니시를 모두 테스트합니다.
3. 마커 색은 흰 카드가 아니라 Black primer 위에서도 테스트합니다.
4. 완성 기준은 실제 눈과 사진 모두에서 확인합니다.

## Step-by-step workflow

1. Black 위에 Charcoal을 얇게 올려 갑옷 중간톤을 만듭니다.
2. Neutral Grey는 넓게 쓰지 않고 모서리와 상단 돌출부에만 둡니다.
3. Bronze는 Tinny Tin에서 시작해 Brassy Brass로 상단만 밝힙니다.
4. Steel은 Dark Gunmetal과 Chainmail로 차갑게 처리해 Bronze와 분리합니다.
5. Cloth는 Gory Red 또는 Hexed Lichen 중 하나를 전군 포인트로 선택합니다.
6. Base는 낮은 채도의 회색/갈색으로 모델을 받칩니다.

## Core color recipe

| Stage | Paint | Purpose |
|---|---|---|
| Primer | Black Primer | 전체 분위기와 깊은 홈 |
| Basecoat | Black, Charcoal | 검은 갑옷의 기준 |
| Layer | Charcoal + Neutral Grey | 상단 면 밝힘 |
| Shade | Black Wash | 갑옷 틈 재정리 |
| Highlight | Neutral Grey | 형태 가독성 |
| Edge Highlight | Neutral Grey + Bonewhite | 시선점 제한 |
| Optional Drybrush | Neutral Grey 매우 가볍게 | 털/베이스에만 권장 |
| Optional Weathering | Charred Brown, Dark Gunmetal | 하단 마모 |
| Brush-only method | 얇은 레이어와 엣지 중심 | 가장 안정적 |
| Airbrush notes | Charcoal을 위쪽 45도에서 얇게 | 큰 갑옷 면 빠른 명도 |
| Recommended varnish | Vallejo Matt Varnish, 금속 Satin 선택 | 어두운 분위기 유지 |

## Marker Tips

마커는 컬러 콘셉트를 빠르게 반복하게 해주는 도구입니다. AK Interactive Real Colors Markers와 AK Playmarkers는 모델링용 아크릴 마커로, 작은 trim, rivet, chain, shield symbol에 특히 편합니다.

| 색 역할 | 마커 사용 | 이유 |
|---|---|---|
| Bronze trim | 권장 | 양각 장식을 빠르게 따라갈 수 있음 |
| Steel chain | 권장 | 사슬 돌출부를 빠르게 찍기 좋음 |
| Rivets | 강력 추천 | 반복되는 금속 점 작업 시간 절약 |
| Horn bands | 제한적 권장 | 뿔 단계 밑칠에 유용 |
| Skin/Faces | 비추천 | 색 변화가 너무 섬세함 |
| Large cloth | 비추천 | 펜 자국과 경계가 남기 쉬움 |
| Fur | 비추천 | 털 방향과 건식 질감이 필요함 |

> ⚠ 마커의 가장 큰 장점은 속도이고, 가장 큰 약점은 표면 결입니다. 넓은 매끈한 면에서는 붓이나 에어브러시가 우월합니다.

## Professional tips

💡 Pro Tip

검은 갑옷을 칠할 때는 "밝은 회색 갑옷"이 되지 않도록 주의하세요. Neutral Grey는 전체 면의 5~10%만 보여도 충분히 형태가 읽힙니다.

💡 Pro Tip

청동은 너무 깨끗하면 질서의 금처럼 보입니다. Sepia Wash와 녹청 weathering을 제한적으로 사용해 오래된 금속처럼 만드세요.

## Common mistakes

- 모든 금속을 같은 은색으로 칠해 재질이 구분되지 않는 것
- 검은 갑옷을 밝게 올리다가 Stormcast 같은 깨끗한 인상을 만드는 것
- 천 색을 너무 선명하게 사용해 Chaos 장식보다 튀는 것
- 마커를 갑옷 중간톤에 써서 스트로크가 남는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 모델이 너무 어둡다 | Charcoal/Neutral Grey 부족 | 상단 엣지만 추가 하이라이트 |
| 모델이 너무 밝다 | Neutral Grey 면적 과다 | Black Wash 또는 Black glaze로 낮춤 |
| 청동이 금색 같다 | Brassy Brass 과다 | Tinny Tin 글레이즈와 Sepia Wash |
| 마커 색이 튄다 | 밑색 대비가 너무 큼 | 붓으로 주변 색 정리 후 바니시 |
