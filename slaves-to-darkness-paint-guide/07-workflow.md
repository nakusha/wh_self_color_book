# 07 Workflow

![Army Workflow](images/workflow-01.jpg)

## Introduction

Spearhead 박스 전체를 완성하려면 좋은 레시피만큼 좋은 순서가 필요합니다. Slaves to Darkness는 trim이 많아 모델 한 명을 완성하고 다음 모델로 넘어가면 색 농도와 금속 밝기가 흔들리기 쉽습니다. 이 장은 기준 모델을 만든 뒤, 공정별로 반복해 전군을 완성하는 workflow를 제시합니다.

## Painting goals

| 목표 | workflow 선택 |
|---|---|
| 전군 통일 | Chaos Warrior 기준 모델 |
| 빠른 진도 | armor, trim, weapon 순서의 batch painting |
| 실수 감소 | 어두운 큰 면 먼저, 작은 밝은 점 나중 |
| 마커 활용 | trim 초벌과 rivet 작업에 제한 사용 |

## Difficulty

Beginner to Intermediate. 순서를 지키면 초보자도 안정적으로 완성할 수 있습니다.

## Preparation

1. Chaos Warrior 한 명을 기준 모델로 선택합니다.
2. 기준 모델에 사용할 색과 희석 비율을 기록합니다.
3. Warriors, Knights, Lord를 한 번에 모두 프라이밍하지 말고 조립 난이도와 접근성을 확인합니다.
4. 마커는 trim 초벌과 rivet 작업에만 사용할 색을 정합니다.
5. 베이스 테마는 전체 박스 시작 전에 확정합니다.

## Step-by-step workflow

1. 기준 Chaos Warrior를 완성합니다.
2. 전체 Warriors의 armor basecoat를 칠합니다.
3. 전체 Warriors의 bronze trim을 칠합니다. 마커를 쓰면 이 단계에서 초벌만 합니다.
4. steel weapons, chains, rivets를 칠합니다.
5. cloth, leather, fur, horn을 작은 영역 순서로 완성합니다.
6. shields와 symbols를 정리합니다.
7. bases를 모두 같은 색과 질감으로 완성합니다.
8. Warriors를 마감한 뒤 Chaos Knights로 같은 색 기준을 확장합니다.
9. 마지막에 Chaos Lord를 칠해 가장 높은 명도와 세부 묘사를 부여합니다.
10. 전체 모델을 한 줄로 세워 밝기와 금속 광택을 비교합니다.

## Marker Tips

마커는 batch painting에서 가장 효과적입니다. Warriors 10명의 rivet이나 shield symbol을 붓으로 모두 초벌하면 시간이 길어지지만, 0.7mm 마커로 점만 찍고 붓으로 wash/highlight를 정리하면 훨씬 빠릅니다.

| Batch 단계 | 마커 추천 | 이유 |
|---|---|---|
| Bronze trim 초벌 | 권장 | 반복 선 작업 시간 감소 |
| Steel chains | 권장 | 돌출부 초벌이 빠름 |
| Rivets | 강력 추천 | 동일한 크기의 점 반복 |
| Horn bands | 제한적 | 작은 단계 밑칠에 편함 |
| Large cloth | 비추천 | 경계와 펜 자국이 남음 |
| Fur | 비추천 | 드라이브러시 질감이 필요 |

> ⚠ 마커 단계에서 완성하려고 하지 마세요. batch painting에서는 빠른 초벌, 붓 단계에서는 품질 정리가 역할입니다.

## Professional tips

💡 Pro Tip

Chaos Lord를 가장 마지막에 칠하세요. 기준 모델보다 10~20% 더 밝고 세밀하게 칠하면 군대의 중심으로 자연스럽게 보입니다.

💡 Pro Tip

Knights는 말과 기수의 밝기 우선순위를 나누세요. 말은 무겁고 어둡게, 기수의 무기와 방패는 더 밝게 두면 시선이 분리됩니다.

## Common mistakes

- 캐릭터부터 시작해 기준 퀄리티가 너무 높아지는 것
- trim을 모두 완성하기 전에 갑옷 수정이 끝나지 않은 것
- 분대마다 금속 밝기가 달라지는 것
- 베이스를 마지막까지 미루어 완성감이 늦어지는 것

## Troubleshooting

| 문제 | 원인 | 해결 |
|---|---|---|
| 분대 색이 다름 | 모델별 완성 방식 | 공정별 batch painting으로 전환 |
| trim이 지저분함 | 갑옷 수정 전 금속 완성 | `Gunmetal`로 경계 정리 후 재하이라이트 |
| 프로젝트가 느림 | 모든 모델 display 품질 목표 | Warrior는 tabletop+, Lord만 display |
| 마커 자국이 보임 | 초벌 후 정리 부족 | wash와 붓 highlight로 통합 |

## Summary

좋은 workflow는 완성 가능성을 높입니다. 기준 Chaos Warrior를 만들고, Warriors, Knights, Lord 순서로 확장하세요. 이제 공통 부위 레시피인 [Armor Recipe](recipes/armor.md)부터 실제 도색으로 들어갑니다.
