# Paint Alternatives

![Paint Alternatives](../images/paint-alternatives-01.jpg)

## Introduction

이 장은 책 전체에서 반복 사용한 주요 도료의 브랜드별 대체표입니다. 완전한 1:1 매칭은 아니지만, 명도와 역할을 기준으로 가까운 대체색을 골랐습니다.

## Theory

대체 도료를 고를 때는 색 이름보다 역할이 중요합니다. Base인지 Highlight인지, 따뜻한지 차가운지, 커버력이 필요한지 글레이즈용인지 먼저 판단하세요.

## Recommended Tools

- 색상 카드
- 동일 프라이머 테스트 스푼
- 무광/새틴 바니시 샘플
- 사진 촬영용 중립 배경

## Difficulty

Beginner to Intermediate. 대체색은 반드시 실제로 칠해 보고 판단해야 합니다.

## Time Required

| 작업 | 시간 |
|---|---|
| 10색 비교 | 1~2시간 |
| 바니시 테스트 | 30분 |

## Step-by-Step Process

1. 같은 프라이머 위에 후보 도료를 칠합니다.
2. Base와 Layer를 실제 레시피처럼 겹쳐 봅니다.
3. 워시와 바니시 후 색 변화를 확인합니다.
4. 사진을 찍어 기준 도료와 비교합니다.
5. 가장 가까운 색보다 가장 안정적으로 반복되는 색을 선택합니다.
6. 마커 대체색은 넓은 면이 아니라 실제 사용 부위 크기로 테스트합니다.

## Common Mistakes

- 병 색만 보고 대체색을 고르는 것
- 바니시 전 색만 비교하는 것
- 브랜드별 광택 차이를 무시하는 것
- 마커 발색을 흰 카드에서만 보고 검은 프라이머 모델에 바로 쓰는 것

> ⚠ 대체 도료는 완전한 복제가 아니라 같은 역할을 수행하는 색입니다. 전군 내에서 일관되면 충분합니다.

## Professional Tips

💡 Pro Tip

한 분대 안에서 브랜드를 섞어도 됩니다. 단, 같은 부위의 Base는 가능하면 한 브랜드로 통일하세요.

💡 Pro Tip

마커는 색상 대체표보다 "작업 대체표"로 보는 편이 정확합니다. `Chrome marker`는 은색 도료 전체를 대체하기보다 극소 반사점과 날 끝을 빠르게 찍는 도구입니다.

## Summary
