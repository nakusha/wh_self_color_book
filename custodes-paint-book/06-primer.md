# 06 Primer

![Primer Test](images/primer-test-01.jpg)

## Introduction

프라이머는 도료가 모델에 붙도록 만드는 접착층이자, 전체 명암의 첫 단계입니다. Custodes처럼 장식이 깊고 금속 도료를 많이 쓰는 모델은 프라이머 품질이 완성도에 직접 영향을 줍니다.

## Theory

프라이머 색은 이후 색의 성격을 바꿉니다.

| Primer | 장점 | 단점 | 추천 용도 |
|---|---|---|---|
| Black | 깊은 그림자, 실수 은폐 | 밝은 색 올리기 어려움 | Royal Navy 갑옷 |
| Grey | 색 확인 쉬움 | 홈 그림자 약함 | 얼굴, 천, 차량 |
| White | 선명한 색 | 실수와 얼룩이 보임 | 에너지, 보석 |
| Zenithal | 명암 지도 제공 | 과하면 얼룩짐 | 고급 레이어링 |

## Recommended Tools

- 스프레이 부스 또는 환기 좋은 공간
- 니트릴 장갑
- 악어 클립과 도색 손잡이
- 에어브러시 0.3mm 이상
- 마스크

## Difficulty

Beginner. 그러나 습도, 거리, 분사량을 무시하면 가장 고치기 어려운 표면 문제가 생깁니다.

## Time Required

| 작업 | 시간 |
|---|---|
| 보병 5명 프라이밍 | 10~20분 |
| 건조 대기 | 30분~24시간 |

## Step-by-Step Process

1. 모델 표면의 먼지와 유분을 제거합니다.
2. 스프레이는 20~30cm 거리에서 짧게 끊어 분사합니다.
3. 한 번에 덮지 말고 얇은 층을 2회 올립니다.
4. 장식 아래쪽과 다리 안쪽을 확인합니다.
5. 완전히 마른 뒤 표면이 거칠거나 번들거리는지 확인합니다.

## Primer Recipe

| Stage | Paint | Purpose |
|---|---|---|
| Primer | Vallejo Surface Primer Black | 접착과 그림자 |
| Base | Dark Prussian Blue | 첫 색층 |
| Layer | Dark Sea Blue zenithal | 위쪽 명도 |
| Shade | 필요 시 Drakenhof Nightshade | 홈 보강 |
| Highlight | Prussian Blue | 엣지 확인 |
| Extreme Highlight | Fenrisian Grey | 프라이머 테스트의 최종 읽힘 |
| Optional Weathering | 없음 | 프라이머 단계에서는 생략 |
| Optional Airbrush Method | Black primer 후 Grey zenithal | 명암 지도 |
| Brush-only Method | 붓 프라이머를 얇게 2회 | 실내 작업 |
| Recommended Varnish | 없음 | 프라이머 위 바니시는 불필요 |

## Common Mistakes

- 습도가 높은 날 스프레이해 표면이 가루처럼 되는 것
- 너무 가까이 분사해 디테일이 묻히는 것
- 완전 건조 전에 베이스를 올려 프라이머가 벗겨지는 것

> ⚠ 프라이머가 거칠게 올라간 모델은 하이라이트를 아무리 잘 넣어도 표면이 지저분해 보입니다. 거친 표면은 건조 후 아주 고운 사포로 정리하세요.

## Professional Tips

💡 Pro Tip

Royal Navy 갑옷에는 블랙 프라이머가 가장 안정적입니다. 단, 얼굴과 보석을 밝게 칠할 부분은 나중에 Grey Seer나 Ivory로 작은 밑칠을 추가하면 색이 훨씬 선명해집니다.

💡 Pro Tip

차량은 패널이 넓어 스프레이 얼룩이 잘 보입니다. [Caladius Grav-tank](units/caladius.md)는 반드시 테스트 분사를 한 뒤 본체에 들어가세요.

## Summary

프라이머는 고치는 작업이 아니라 예방하는 작업입니다. 좋은 프라이머는 [Armor Recipe](armor/10-armor.md)의 남색 레이어와 [Gold](armor/11-gold.md)의 금속 발색을 모두 안정시킵니다.

## Checklist

- [ ] 모델 표면을 깨끗하게 준비했다.
- [ ] 프라이머를 얇게 2회 올렸다.
- [ ] 장식 안쪽까지 덮였다.
- [ ] 표면이 거칠지 않다.
- [ ] 충분히 건조한 뒤 다음 단계로 넘어갔다.
