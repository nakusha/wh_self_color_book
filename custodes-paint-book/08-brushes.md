# 08 Brushes

![Brush Set](images/brush-set-01.jpg)

## Introduction

좋은 브러시는 작은 브러시가 아니라 끝이 잘 모이는 브러시입니다. Custodes의 장식은 많지만, 모든 작업을 000호로 할 필요는 없습니다.

## Theory

브러시는 물 저장량, 탄성, 끝 모임으로 평가합니다.

| 브러시 | 용도 | 추천 크기 |
|---|---|---|
| 라운드 브러시 | 대부분의 베이스와 레이어 | 1, 2 |
| 디테일 브러시 | 눈, 보석, 미세 하이라이트 | 0 |
| 드라이브러시 | 베이스, 털, 질감 | Small, Medium |
| 낡은 브러시 | 워시, 피그먼트, 접착제 | 아무 크기 |

## Recommended Paints

브러시 장에서는 도료보다 작업별 점도가 중요합니다.

## Difficulty

Beginner. 관리만 잘하면 저렴한 브러시로도 충분히 좋은 결과를 낼 수 있습니다.

## Time Required

| 작업 | 시간 |
|---|---|
| 브러시 세척 | 작업 후 5분 |
| 끝 정리 | 작업 중 수시 |

## Step-by-Step Process

1. 새 브러시는 보호 풀을 물로 풀어냅니다.
2. 도료는 브러시 털의 중간 이상까지 묻히지 않습니다.
3. 팔레트에서 브러시를 굴려 끝을 모읍니다.
4. 엣지 하이라이트는 브러시 끝보다 옆면을 사용합니다.
5. 작업 후 비누로 세척하고 끝을 모아 말립니다.

## Brush Control Recipe

| Stage | Paint | Purpose |
|---|---|---|
| Primer | 없음 | 브러시 보호 |
| Base | Dark Prussian Blue | 큰 브러시로 매끈하게 |
| Layer | Prussian Blue | 중간 브러시로 면 제어 |
| Shade | Agrax Earthshade | 낡은 브러시 사용 |
| Highlight | Prussian Blue | 1호 끝으로 엣지 |
| Extreme Highlight | Fenrisian Grey | 0호로 점 |
| Optional Weathering | Rhinox Hide | 스펀지 또는 낡은 브러시 |
| Optional Airbrush Method | 브러시 사용 최소화 | 큰 면 시간 절약 |
| Brush-only Method | 2호 베이스, 1호 레이어, 0호 극점 | 안정적인 분업 |
| Recommended Varnish | 브러시 바니시는 별도 낡은 브러시 | 좋은 브러시 보호 |

## Common Mistakes

- 작은 작업은 무조건 작은 브러시로 해야 한다고 생각하는 것
- 도료가 금속 페룰 안으로 들어가 끝이 갈라지는 것
- 드라이브러시에 좋은 브러시를 사용하는 것

> ⚠ 바니시, 피그먼트, 접착제는 좋은 브러시의 수명을 빠르게 줄입니다. 반드시 전용 낡은 브러시를 쓰세요.

## Professional Tips

💡 Pro Tip

엣지 하이라이트가 떨린다면 손목을 공중에 띄우지 말고 양손을 서로 기대세요. 브러시 제어는 손기술보다 자세의 문제인 경우가 많습니다.

💡 Pro Tip

브러시 끝이 갈라졌다고 바로 버리지 마세요. 워시, 베이스 텍스처, 피그먼트 작업용으로 등급을 내려 쓰면 좋습니다.
