# Adeptus Custodes Paint Book

![Custodes Cover Reference](images/custodes-cover-reference.jpg)

이 책은 Adeptus Custodes를 Royal Navy 계열의 깊은 남색 갑옷과 고급스러운 금장으로 완성하기 위한 실전 페인팅 가이드입니다. 초보자는 순서대로 따라 칠 수 있고, 숙련자는 색 선택, 명암 설계, 바니시, 유닛별 응용 레시피를 참고해 일관된 전군 도색 기준을 세울 수 있도록 구성했습니다.

![Royal Navy Custodes Units](images/royal-navy-custodes-units-reference-sheet.png)

## Image Notice

이 프로젝트의 이미지는 Warhammer 40,000 공식 faction 페이지와 Warhammer Community의 공개 이미지를 로컬 참고용으로 저장한 것입니다. 저작권은 Games Workshop Limited에 있으며, 공개 배포나 상업적 사용을 준비할 때는 직접 촬영 이미지, 라이선스 이미지, 또는 명시적 허가를 받은 이미지로 교체하세요. 출처는 [images/SOURCES.txt](images/SOURCES.txt)에 기록했습니다.

## How to Use

- 처음 시작한다면 [Introduction](01-introduction.md), [Custodes](02-custodes.md), [Royal Navy Scheme](03-royal-navy-scheme.md)를 먼저 읽으세요.
- 실제 도색 전에는 [Primer](06-primer.md), [Paints](07-paints.md), [Brushes](08-brushes.md), [Tools](09-tools.md), [Varnish](10-varnish.md)를 준비 체크리스트로 사용하세요.
- 모델을 칠할 때는 [Workflow](11-workflow.md)를 기본 순서로 삼고, 부위별 세부 처리는 `armor/` 챕터를 참조하세요.
- 특정 유닛은 `units/` 챕터의 레시피를 따라가면 전체 군대의 색감이 흔들리지 않습니다.
- 베이스는 `basing/` 중 하나를 선택하고 전군에 반복 적용하는 것을 권장합니다.
